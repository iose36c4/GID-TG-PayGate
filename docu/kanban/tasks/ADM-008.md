# [[ADM-008]] Feature Flags: Rollout Gradual, Kill Switches, A/B Testing Infra

## Descripción
Implementar sistema de feature flags en Admin: rollout gradual por porcentaje de usuarios, kill switches de emergencia, infraestructura para A/B testing.

## Código de Ejemplo
```php
// app/Models/FeatureFlag.php
class FeatureFlag extends Model
{
    protected $fillable = [
        'key', 'name', 'description', 'enabled', 
        'rollout_percentage', 'target_groups', 
        'conditions', 'kill_switch', 'expires_at',
    ];

    protected $casts = [
        'enabled' => 'boolean',
        'rollout_percentage' => 'integer',
        'target_groups' => 'array',
        'conditions' => 'array',
        'kill_switch' => 'boolean',
        'expires_at' => 'datetime',
    ];

    public function isEnabledFor(User $user): bool
    {
        if (!$this->enabled || $this->kill_switch) return false;
        if ($this->expires_at && $this->expires_at->isPast()) return false;
        
        // Verificar grupos objetivo
        if ($this->target_groups && !$this->matchesGroups($user)) return false;
        
        // Verificar condiciones personalizadas
        if ($this->conditions && !$this->evaluateConditions($user)) return false;
        
        // Rollout porcentual
        if ($this->rollout_percentage < 100) {
            $hash = crc32($user->id . $this->key);
            return ($hash % 100) < $this->rollout_percentage;
        }
        
        return true;
    }
}
```

```php
// app/Services/FeatureFlagService.php
class FeatureFlagService
{
    public function isEnabled(string $key, User $user = null): bool
    {
        $flag = \App\Models\FeatureFlag::where('key', $key)->first();
        
        if (!$flag) return false;
        
        $user = $user ?? auth()->user();
        if (!$user) return $flag->enabled && !$flag->kill_switch;
        
        return $flag->isEnabledFor($user);
    }

    public function getAllForUser(User $user): array
    {
        return \App\Models\FeatureFlag::where('enabled', true)
            ->where('kill_switch', false)
            ->where(function($q) {
                $q->whereNull('expires_at')->orWhere('expires_at', '>', now());
            })
            ->get()
            ->filter(fn($flag) => $flag->isEnabledFor($user))
            ->pluck('key')
            ->toArray();
    }
}
```

```php
// app/Http/Middleware/FeatureFlagMiddleware.php
class FeatureFlagMiddleware
{
    public function handle(Request $request, Closure $next, string $flag)
    {
        if (!app(FeatureFlagService::class)->isEnabled($flag)) {
            abort(404, "Feature '$flag' not available");
        }
        return $next($request);
    }
}
```

## Criterios de Aceptación
- [ ] CRUD Feature Flags: key, name, description, enabled, kill_switch, rollout_percentage, target_groups, conditions, expires_at
- [ ] Lista: tabla con flag, estado ON/OFF, rollout %, kill switch toggle, target_groups, expira
- [ ] Rollout gradual: 0-100% consistente por user_id (crc32 hash)
- [ ] Kill Switch: OFF inmediato global, override rollout
- [ ] Target groups: array de strings (beta, premium, staff, etc.)
- [ ] Conditions: JSON con reglas (ej: plan=premium, country=AR)
- [ ] Expiración: fecha opcional, auto-disable al vencer
- [ ] Middleware: `feature:flag_name` para rutas
- [ ] Helper blade: `@feature('flag') ... @endfeature`
- [ ] Helper PHP: `feature_enabled('flag')`, `FeatureFlagService::isEnabled()`
- [ ] Kill switch: override inmediato, log de activación
- [ ] Testing: unit tests para rollout consistency, kill switch override

## Notas Técnicas
- Rollout: `crc32(user_id . flag_key) % 100 < rollout_percentage`
- Consistency: mismo usuario siempre mismo bucket
- Cache: feature flags en Redis con TTL 5 min
- Kill switch: invalida cache inmediatamente
- Conditions: evaluar con `Illuminate\Support\Arr::get()` / custom evaluator
- A/B testing: asignación determinística, métricas por variant

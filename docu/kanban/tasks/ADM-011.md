# [[ADM-011]] Compliance AFIP/ARCA: CAE, Factura Electrónica, RG 4367/4368/4369, ARCA Web Services

## Descripción
Implementar panel de compliance AFIP/ARCA en Admin: monitoreo de CAE, estado factura electrónica, cumplimiento RG 4367/4368/4369, integración ARCA Web Services.

## Código de Ejemplo
```php
// app/Domains/Staff/Http/Controllers/Admin/ComplianceController.php
namespace App\Domains\Staff\Http\Controllers\Admin;

use App\Models\Invoice;
use App\Services\AfipWsfeService;

class ComplianceController extends Controller
{
    public function index()
    {
        $stats = [
            'pending_cae' => Invoice::where('status', 'draft')->count(),
            'authorized_today' => Invoice::where('status', 'authorized')
                ->whereDate('created_at', today())->count(),
            'rejected_today' => Invoice::where('status', 'rejected')
                ->whereDate('created_at', today())->count(),
            'expired_cae' => Invoice::where('status', 'authorized')
                ->where('cae_due_date', '<', now())->count(),
        ];

        $recentInvoices = Invoice::with(['channel', 'receiver'])
            ->latest()
            ->paginate(50);

        return view('domains.staff.admin.compliance.index', compact('stats', 'recentInvoices'));
    }

    public function retryCae(Invoice $invoice)
    {
        if ($invoice->status !== 'rejected' && $invoice->status !== 'draft') {
            return back()->with('error', 'Solo facturas rechazadas o en borrador pueden reintentarse');
        }

        $afipService = app(AfipWsfeService::class);
        $result = $afipService->retryAuthorization($invoice);

        return back()->with($result['success'] ? 'success' : 'error', $result['message']);
    }

    public function downloadXml(Invoice $invoice, string $type)
    {
        $xml = $type === 'request' ? $invoice->afip_xml_request : $invoice->afip_xml_response;
        
        if (!$xml) {
            abort(404, 'XML no disponible');
        }

        return response($xml)
            ->header('Content-Type', 'application/xml')
            ->header('Content-Disposition', "attachment; filename=\"{$invoice->number}_{$type}.xml\"");
    }

    public function checkAfipStatus()
    {
        $afipService = app(AfipWsfeService::class);
        $status = $afipService->getServerStatus();
        
        return response()->json($status);
    }
}
```

## Criterios de Aceptación
- [ ] Dashboard con métricas: pendientes CAE, autorizadas hoy, rechazadas hoy, CAE vencidos
- [ ] Estado servidor AFIP/ARCA: WSFE v1, WS SR Padrón A13 (online/offline/degradado)
- [ ] Lista facturas con filtros: estado, fecha, tipo, CAE
- [ ] Acciones: reintentar CAE (rechazadas/borrador), descargar XML request/response
- [ ] Descarga XML request/response AFIP para auditoría
- [ ] Cumplimiento RG 4367 (factura electrónica), RG 4368 (CAE+QR), RG 4369 (clase M)
- [ ] Botón "Actualizar estado AFIP" con consulta dummy
- [ ] Métricas: tasa éxito CAE, tiempo promedio respuesta, rechazos por código error
- [ ] Alertas: CAE vencidos, rechazos masivos, servidor AFIP caído

## Notas Técnicas
- WSFE v1: `wswhomo.afip.gov.ar` (testing) / `servicios1.afip.gov.ar` (production)
- WS SR Padrón A13: consulta contribuyentes (CUIT, denominación, impuestos, domicilio)
- Dummy: test conectividad sin consumir CAE
- CAE: 14 dígitos + 2 dígitos verificación (módulo 11)
- QR AFIP: URL verificación con parámetros base64
- PDF417: código barras 2D obligatorio (RG 4368/2014)
- Certificado digital: .crt + .key OpenSSL 2048 bits, vigencia 1 año

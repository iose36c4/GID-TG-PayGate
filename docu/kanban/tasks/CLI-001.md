# [[CLI-001]] Dashboard Usuario: Resumen Accesos, Próximas Renovaciones, Gasto Total

## Descripción
Implementar dashboard principal del área de cliente (CLI): resumen de accesos activos, próximas renovaciones, gasto total, accesos rápidos.

## Código de Ejemplo
```php
// app/Domains/Public/Http/Controllers/ClientDashboardController.php
namespace App\Domains\Public\Http\Controllers;

use App\Models\{Subscription, Payment, User};

class ClientDashboardController extends Controller
{
    public function index()
    {
        $user = auth()->user();
        
        $activeSubscriptions = Subscription::where('user_id', auth()->id())
            ->where('status', 'active')
            ->with(['channel', 'channel.owner'])
            ->get();

        $upcomingRenewals = $activeSubscriptions->filter(fn($s) => 
            $s->renews_at && $s->renews_at->diffInDays(now()) <= 7
        )->sortBy('renews_at');

        $totalSpent = Payment::where('user_id', auth()->id())
            ->where('status', 'approved')
            ->sum('amount');

        $recentActivity = $user->activityLog()
            ->latest()
            ->take(10)
            ->get();

        return view('domains.public.client.dashboard', compact(
            'activeSubscriptions',
            'upcomingRenewals',
            'totalSpent',
            'recentActivity'
        ));
    }
}
```

## Criterios de Aceptación
- [ ] 3 Stats Cards: Canales Activos, Próximas Renovaciones (7d), Gasto Total
- [ ] Lista canales activos: thumbnail, nombre, owner, precio, fecha renovación (máx 5 + link "ver todos")
- [ ] Próximas renovaciones (≤7 días): ordenadas por fecha, badge urgencia (rojo ≤3d, amarillo ≤7d)
- [ ] Actividad reciente: 10 últimos eventos (icono, descripción, tiempo relativo)
- [ ] Responsive: grid 1 col móvil, 2 cols desktop
- [ ] Links a vistas detalladas: canales, pagos, renovaciones

## Notas Técnicas
- Usar layout `layouts.dashboard` (UI-003)
- Queries optimizadas: eager loading channel, owner
- Renovaciones: `renews_at` en Subscription, filtrar `<= now()->addDays(7)`
- Gasto total: sum `amount` en Payment donde `status=approved` y `user_id=auth()`

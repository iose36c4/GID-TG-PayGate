# [[CLI-002]] Mis Canales: Activos (con Invite Link), Historial, Cancelados

## Descripción
Implementar vista completa de canales del usuario: activos con invite link de Telegram, historial de suscripciones pasadas, canales cancelados con opción de reactivar.

## Código de Ejemplo
```php
// app/Domains/Public/Http/Controllers/ClientChannelController.php
namespace App\Domains\Public\Http\Controllers;

use App\Models\{Subscription, ChannelPago};

class ClientChannelController extends Controller
{
    public function index()
    {
        $activeSubscriptions = Subscription::where('user_id', auth()->id())
            ->where('status', 'active')
            ->with(['channel', 'channel.owner', 'channel.category'])
            ->latest()
            ->paginate(10);

        $pastSubscriptions = Subscription::where('user_id', auth()->id())
            ->whereIn('status', ['cancelled', 'expired'])
            ->with(['channel', 'channel.owner'])
            ->latest()
            ->paginate(10);

        return view('domains.public.client.channels.index', compact(
            'activeSubscriptions',
            'pastSubscriptions'
        ));
    }

    public function show(Subscription $subscription)
    {
        $this->authorize('view', $subscription);
        
        $subscription->load(['channel', 'channel.owner', 'payments', 'invoices']);
        
        return view('domains.public.client.channels.show', compact('subscription'));
    }

    public function reactivate(Subscription $subscription)
    {
        $this->authorize('manage', $subscription);
        
        if ($subscription->status !== 'cancelled' && $subscription->status !== 'expired') {
            return back()->with('error', 'Solo se pueden reactivar suscripciones canceladas o expiradas');
        }

        // Crear nueva suscripción o reactivar
        $newSubscription = $subscription->channel->subscriptions()->create([
            'user_id' => auth()->id(),
            'status' => 'pending_payment',
            'price' => $subscription->channel->price,
            'currency' => $subscription->channel->currency,
            'billing_cycle' => $subscription->billing_cycle ?? 'monthly',
        ]);

        return redirect()->route('checkout.create', $subscription->channel)
            ->with('info', 'Completa el pago para reactivar tu acceso');
    }
}
```

## Criterios de Aceptación
- [ ] Tabs: Activos (con contador) / Historial (con contador)
- [ ] Activos: Card por suscripción con thumbnail, nombre, owner, categoría, verificado, precio, renovación
- [ ] Botones: "Detalle" (va a show), "Acceder al Canal" (link Telegram si invite_link existe)
- [ ] Historial: Card por suscripción pasada con estado badge (cancelled/expired), fecha fin, botón Reactivar
- [ ] Reactivar: Crea nueva suscripción pending_payment, redirige a checkout
- [ ] Paginación en ambas tabs (10 por página)
- [ ] Empty states ilustrados para ambas tabs vacías
- [ ] Responsive: stack en móvil, horizontal en desktop

## Notas Técnicas
- Livewire o Alpine.js para tabs sin recarga
- Policy: `view` own subscriptions, `manage` para reactivar
- Invite link: almacenado en `subscription.telegram_invite_link` (generado en checkout)
- Reactivación: crea nueva subscription `pending_payment`, no reactiva la antigua

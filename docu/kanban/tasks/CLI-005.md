# [[CLI-005]] Soporte: Crear Ticket, Ver Mis Tickets, FAQ Integrada

## Descripción
Implementar sección de soporte en área cliente: crear ticket, listar/ver tickets propios, FAQ integrada con búsqueda.

## Código de Ejemplo
```php
// app/Domains/Public/Http/Controllers/ClientSupportController.php
namespace App\Domains\Public\Http\Controllers;

use App\Models\{Ticket, TicketCategory, KnowledgeBaseArticle};

class ClientSupportController extends Controller
{
    public function index()
    {
        $tickets = Ticket::where('user_id', auth()->id())
            ->with(['category', 'assignedTo', 'replies' => fn($q) => $q->latest()->take(1)])
            ->latest()
            ->paginate(15);

        return view('domains.public.client.support.index', compact('tickets'));
    }

    public function create()
    {
        $categories = TicketCategory::where('is_active', true)->where('visible_to_client', true)->get();
        return view('domains.public.client.support.create', compact('categories'));
    }

    public function store(TicketStoreRequest $request)
    {
        $ticket = Ticket::create([
            'user_id' => auth()->id(),
            'category_id' => $request->category_id,
            'subject' => $request->subject,
            'description' => $request->description,
            'priority' => $request->priority ?? 'normal',
            'status' => 'open',
            'channel' => 'web',
        ]);

        // Notificar staff via Telegram/Email
        app(\App\Services\TelegramService::class)->notifyStaffNewTicket($ticket);

        return redirect()->route('client.support.show', $ticket)
            ->with('success', 'Ticket creado. Te responderemos pronto.');
    }

    public function show(Ticket $ticket)
    {
        $this->authorize('view', $ticket);
        $ticket->load(['category', 'assignedTo', 'replies.user', 'replies.attachments']);
        return view('domains.public.client.support.show', compact('ticket'));
    }

    public function reply(Ticket $ticket, TicketReplyRequest $request)
    {
        $this->authorize('reply', $ticket);
        
        $reply = $ticket->replies()->create([
            'user_id' => auth()->id(),
            'message' => $request->message,
            'is_internal' => false,
            'attachments' => $request->attachments ?? [],
        ]);

        // Notificar staff
        app(\App\Services\TelegramService::class)->notifyStaffTicketReply($ticket, $reply);

        return back()->with('success', 'Respuesta enviada');
    }

    public function close(Ticket $ticket)
    {
        $this->authorize('close', $ticket);
        $ticket->update(['status' => 'closed', 'closed_at' => now()]);
        return back()->with('success', 'Ticket cerrado');
    }

    public function knowledgeBase()
    {
        $categories = KnowledgeBaseArticle::where('is_published', true)
            ->where('visible_to_client', true)
            ->with('category')
            ->get()
            ->groupBy('category.name');

        $featured = KnowledgeBaseArticle::where('is_published', true)
            ->where('is_featured', true)
            ->take(5)
            ->get();

        return view('domains.public.client.support.knowledge-base', compact('categories', 'featured'));
    }

    public function searchKnowledgeBase(Request $request)
    {
        $query = $request->get('q');
        $articles = KnowledgeBaseArticle::where('is_published', true)
            ->where('visible_to_client', true)
            ->where(function($q) use ($query) {
                $q->where('title', 'LIKE', "%{$query}%")
                  ->orWhere('content', 'LIKE', "%{$query}%")
                  ->orWhere('tags', 'LIKE', "%{$query}%");
            })
            ->with('category')
            ->paginate(10);

        return view('domains.public.client.support.search', compact('articles', 'query'));
    }
}
```

## Criterios de Aceptación
- [ ] Dashboard soporte: 3 cards acceso rápido (KB, Nuevo Ticket, Mis Tickets)
- [ ] Crear ticket: categoría, prioridad (low/normal/high/urgent), asunto, descripción, adjuntos
- [ ] Mis tickets: tabla con asunto, categoría, prioridad (badge), estado (badge), última actividad, paginación
- [ ] Detalle ticket: historial cronológico mensajes, responder, adjuntos, cerrar ticket
- [ ] Base de conocimiento: categorías con artículos, artículos destacados, búsqueda full-text
- [ ] Búsqueda KB: full-text en título, contenido, tags
- [ ] Artículo KB: título, excerpt, categoría, contenido completo, feedback útil/no útil
- [ ] Notificaciones: Telegram/Email a staff en nuevo ticket y respuestas
- [ ] Prioridades: low/normal/high/urgent con badges de color
- [ ] Estados: open, pending, waiting, closed con badges de color

## Notas Técnicas
- Ticket: belongsTo User, Category, assignedTo; hasMany Replies, Attachments
- Reply: belongsTo Ticket, User; belongsTo parent (threaded)
- Attachment: polymorphic (Ticket, Reply)
- Notificaciones: Queue job para Telegram/Email
- KB Article: belongsTo Category, User; tags JSON, is_published, is_featured
- Full-text search: MySQL FULLTEXT o Meilisearch/Algolia
- Feedback KB: reaction (útil/no útil) en article

# [[CLI-006]] Notificaciones: Centro Notificaciones (In-App + Email + Telegram Opt-in)

## Descripción
Implementar centro de notificaciones unificado en área cliente: notificaciones in-app con centro de notificaciones, email, y opt-in para Telegram.

## Código de Ejemplo
```php
// app/Domains/Public/Http/Controllers/ClientNotificationController.php
namespace App\Domains\Public\Http\Controllers;

use App\Models\Notification;

class ClientNotificationController extends Controller
{
    public function index()
    {
        $notifications = auth()->user()->notifications()
            ->latest()
            ->paginate(20);

        return view('domains.public.client.notifications.index', compact('notifications'));
    }

    public function markAsRead(Notification $notification)
    {
        $this->authorize('update', $notification);
        $notification->markAsRead();
        return response()->json(['success' => true]);
    }

    public function markAllAsRead()
    {
        auth()->user()->unreadNotifications->markAsRead();
        return response()->json(['success' => true]);
    }

    public function destroy(Notification $notification)
    {
        $this->authorize('delete', $notification);
        $notification->delete();
        return response()->json(['success' => true]);
    }

    public function preferences()
    {
        return view('domains.public.client.notifications.preferences', [
            'user' => auth()->user(),
        ]);
    }

    public function updatePreferences(NotificationPreferenceRequest $request)
    {
        $user = auth()->user();
        $user->settings = array_merge($user->settings ?? [], [
            'notifications' => $request->validated(),
        ]);
        $user->save();

        return redirect()->back()->with('success', 'Preferencias actualizadas');
    }
}
```

<script>
function markAllAsRead() {
    fetch('{{ route("client.notifications.mark-all-read") }}', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json', 'X-CSRF-TOKEN': '{{ csrf_token() }}' }
    }).then(() => location.reload());
}

function markAsRead(id) {
    fetch(`/client/notifications/${id}/read`, { method: 'PUT', headers: { 'X-CSRF-TOKEN': '{{ csrf_token() }}' }})
        .then(() => location.reload());
}

function deleteNotification(id) {
    if (confirm('¿Eliminar esta notificación?')) {
        fetch(`/client/notifications/${id}`, { method: 'DELETE', headers: { 'X-CSRF-TOKEN': '{{ csrf_token() }}' }})
            .then(() => location.reload());
    }
}
</script>

## Criterios de Aceptación
- [ ] Centro notificaciones: lista paginada, estado leído/no leído (anillo azul), acciones marcar leído/eliminar
- [ ] Marcar todo como leído (botón + API)
- [ ] Preferencias: canales globales (In-App, Email, Telegram) + por tipo de notificación
- [ ] Tipos: nueva sub, renovación, retiro, pago fallido, respuesta ticket, nueva feature
- [ ] Canales por tipo: In-App (todos), Email (críticos + resumen), Telegram (opt-in, solo críticos)
- [ ] Badge contador no leídos en header/nav
- [ ] Tiempo real: WebSocket/Pusher para notificaciones instantáneas (opcional v1.1)
- [ ] Agrupación por fecha (hoy, ayer, esta semana, más antiguo)

## Notas Técnicas
- Laravel Notifications + Database channel + Broadcast (Pusher/Laravel Echo)
- Notification::database() para in-app, MailChannel para email, custom TelegramChannel
- Settings en user.settings.notifications JSON
- Database notifications table con índices: user_id + read_at + created_at
- WebSocket: Laravel Echo + Pusher/Soketi para tiempo real (v1.1)

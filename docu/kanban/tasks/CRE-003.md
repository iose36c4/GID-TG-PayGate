# [[CRE-003]] Canales CRUD: Vincular Bot (Token Encrypted), Canal/Grupo ID, Precios, Moneda, Trial

## Descripción
Implementar CRUD completo de canales en panel de creadores: crear, editar, eliminar, listar con token de bot cifrado, configuración de canal/grupo Telegram, precios, moneda y período de prueba.

## Código de Ejemplo
```php
// app/Domains/Creadores/Http/Controllers/ChannelController.php
namespace App\Domains\Creadores\Http\Controllers;

class ChannelController extends Controller
{
    public function __construct(protected ChannelService $channelService) {}

    public function index()
    {
        $channels = auth()->user()->channels()
            ->withCount(['subscriptions' => fn($q) => $q->where('status', 'active')])
            ->withSum('subscriptions as mrr', 'price')
            ->latest()
            ->paginate(10);

        return view('domains.creadores.channels.index', compact('channels'));
    }

    public function create()
    {
        $categories = Category::where('is_active', true)->get();
        return view('domains.creadores.channels.create', compact('categories'));
    }

    public function store(ChannelStoreRequest $request)
    {
        $channel = auth()->user()->channels()->create([
            'name' => $request->name,
            'slug' => Str::slug($request->name),
            'description' => $request->description,
            'category_id' => $request->category_id,
            'telegram_chat_id' => $request->telegram_chat_id,
            'telegram_bot_token' => Crypt::encryptString($request->telegram_bot_token),
            'telegram_bot_username' => $request->telegram_bot_username,
            'price' => $request->price,
            'currency' => $request->currency ?? 'ARS',
            'billing_cycle' => $request->billing_cycle ?? 'monthly',
            'trial_days' => $request->trial_days ?? 0,
            'status' => 'active',
        ]);

        return redirect()->route('creadores.channels.index')
            ->with('success', 'Canal creado correctamente');
    }

    public function edit(ChannelPago $channel)
    {
        $this->authorize('manage', $channel);
        $categories = Category::where('is_active', true)->get();
        return view('domains.creadores.channels.edit', compact('channel', 'categories'));
    }

    public function update(ChannelUpdateRequest $request, ChannelPago $channel)
    {
        $this->authorize('manage', $channel);

        $data = $request->validated();
        if ($request->filled('telegram_bot_token')) {
            $data['telegram_bot_token'] = Crypt::encryptString($request->telegram_bot_token);
        }

        $channel->update($request->validated());
        return redirect()->route('creadores.channels.index')
            ->with('success', 'Canal actualizado correctamente');
    }

    public function destroy(ChannelPago $channel)
    {
        $this->authorize('delete', $channel);
        $channel->delete();
        return back()->with('success', 'Canal eliminado');
    }

    public function testBotToken(ChannelPago $channel)
    {
        $this->authorize('manage', $channel);
        
        $telegramService = app(\App\Services\TelegramService::class);
        $token = Crypt::decryptString($channel->telegram_bot_token);
        $botInfo = $telegramService->getBotInfo($token);

        if ($botInfo['ok']) {
            return response()->json([
                'success' => true,
                'bot_name' => $botInfo['result']['first_name'],
                'username' => $botInfo['result']['username'],
            ]);
        }

        return response()->json(['success' => false, 'error' => 'Token inválido']);
    }
}
```

## Criterios de Aceptación
- [ ] Listado: tabla paginada (10/page) con nombre, categoría, precio, subs, MRR, estado, bot status
- [ ] Crear: nombre, slug auto, descripción, categoría, cover image, precio, moneda, ciclo, trial days, bot token (encrypted), chat ID, bot username
- [ ] Editar: mismos campos + test bot token button (AJAX)
- [ ] Eliminar: confirmación modal, soft delete opcional v1.1
- [ ] Token bot: cifrado AES-256 en BD, validación via API getMe
- [ ] Test bot token: botón AJAX que llama getMe, muestra nombre/username
- [ ] Filtros: estado (active/pending/suspended), categoría, búsqueda por nombre
- [ ] Permisos: policy ChannelPolicy (view, create, update, delete, testBot)

## Notas Técnicas
- Token bot cifrado: `Crypt::encryptString()` / `decryptString()`
- Validación token: llamada `getMe` a Telegram Bot API
- Slug auto-generado: `Str::slug($name)` + unique check
- Cover image: upload a S3/local, resize 1200x630, WebP
- MRR calculado: suma de `price` de subscripciones activas
- Permissions: policy `ChannelPolicy` (view, create, update, delete, testBot)

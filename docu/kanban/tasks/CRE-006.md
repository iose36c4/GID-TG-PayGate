# [[CRE-006]] Retiros: Configurar Cuenta (Tokenizado Stripe Connect/MercadoPago), Solicitar, Historial

## Descripción
Implementar sistema de retiros para creadores: configuración de cuenta bancaria (CBU/CVU, alias) y Stripe Connect/MercadoPago, solicitud de retiro, historial con estados.

## Código de Ejemplo
```php
// app/Domains/Creadores/Http/Controllers/PayoutController.php
namespace App\Domains\Creadores\Http\Controllers;

class PayoutController extends Controller
{
    public function index()
    {
        $payouts = auth()->user()
            ->channels()
            ->where('status', 'active')
            ->with(['payouts' => fn($q) => $q->latest()])
            ->get()
            ->flatMap->payouts
            ->sortByDesc('created_at');

        return view('domains.creadores.payouts.index', compact('payouts'));
    }

    public function create()
    {
        $user = auth()->user();
        $channels = $user->channels()->where('status', 'active')->get();
        
        $gateways = [];
        foreach ($channels as $channel) {
            $gateways = array_merge($gateways, $channel->configured_gateways);
        }

        return view('domains.creadores.payouts.create', compact('channels', 'gateways'));
    }

    public function store(PayoutRequest $request)
    {
        $user = auth()->user();
        $channel = ChannelPago::findOrFail($request->channel_id);
        
        $this->authorize('manage', $channel);

        // Verificar saldo disponible
        $available = $this->calculateAvailableBalance($channel);
        if ($request->amount > $available) {
            return back()->withErrors(['amount' => 'Saldo insuficiente']);
        }

        if ($request->amount < $channel->payoutSchedule->minimum_amount) {
            return back()->withErrors(['amount' => 'Monto menor al mínimo']);
        }

        $payout = Payout::create([
            'channel_pago_id' => $request->channel_id,
            'amount' => $request->amount,
            'currency' => $channel->currency,
            'gateway' => $request->gateway,
            'status' => 'pending',
            'reference' => "PAYOUT-{$request->channel_id}-" . time(),
        ]);

        // Procesar según gateway
        $this->processPayout($payout);

        return redirect()->route('creadores.payouts.index')
            ->with('success', 'Solicitud de retiro enviada');
    }

    private function processPayout(Payout $payout)
    {
        $channel = $payout->channel;
        
        switch ($payout->gateway) {
            case 'mercadopago':
                $this->payoutViaMercadoPago($payout);
                break;
            case 'stripe':
                $this->payoutViaStripe($payout);
                break;
            case 'bank_transfer':
                $this->queueBankTransfer($payout);
                break;
        }
    }

    private function payoutViaMercadoPago(Payout $payout)
    {
        $mpService = app(\App\Services\MercadoPagoArgentinaService::class);
        $channel = $payout->channel;
        
        try {
            $transfer = $mpService->createTransfer([
                'amount' => $payout->amount,
                'currency' => $payout->currency,
                'destination_account' => $channel->mercadopago_account_id,
                'description' => "Retiro TG-PayGate - Canal {$payout->channel->name}",
            ]);

            $payout->update([
                'status' => 'completed',
                'external_id' => $transfer['id'],
                'completed_at' => now(),
            ]);
        } catch (\Exception $e) {
            $payout->update(['status' => 'failed', 'failure_reason' => $e->getMessage()]);
        }
    }

    private function queueBankTransfer(Payout $payout)
    {
        // Crear orden de transferencia bancaria para procesamiento manual
        BankTransferOrder::create([
            'payout_id' => $payout->id,
            'channel_pago_id' => $payout->channel_pago_id,
            'amount' => $payout->amount,
            'currency' => $payout->currency,
            'destination_cbu' => $payout->channel->bank_cbu_cvu,
            'destination_alias' => $payout->channel->bank_alias,
            'beneficiary' => $payout->channel->bank_holder_name,
            'beneficiary_cuit' => $payout->channel->bank_holder_cuit_cuil,
            'bank_name' => $payout->channel->bank_name,
            'status' => 'pending',
            'reference' => "PAYOUT-{$payout->id}-" . now()->format('YmdHis'),
        ]);

        $payout->update(['status' => 'pending_transfer']);
    }
}
```

## Criterios de Aceptación
- [ ] Configurar cuenta: Stripe Connect (onboarding), MercadoPago (credenciales), Banco (CBU/CVU, alias, titular, CUIT)
- [ ] Tokenizado: secrets encriptados con `Crypt::encryptString()`
- [ ] Solicitar retiro: select canal, monto (>= mínimo), gateway
- [ ] Validación: monto <= saldo disponible, monto >= mínimo retiro
- [ ] Procesamiento: MP transfer API, Stripe transfer, orden transferencia manual
- [ ] Historial: tabla con fecha, monto, gateway, estado, referencia, descargar comprobante
- [ ] Estados: pending, processing, completed, failed, pending_transfer (banco)
- [ ] Notificaciones: email + telegram al completar/fallar
- [ ] Comprobante PDF descargable

## Notas Técnicas
- MercadoPago: `/v1/transfers` con `destination_account_id`
- Stripe: `Transfer::create` con `destination` account_id
- Banco: crea `BankTransferOrder` para staff, status `pending_transfer`
- Job `ProcessPayouts` diario para automáticos
- Idempotency: `external_id` único por payout
- Notificaciones: email + telegram al completar/fallar

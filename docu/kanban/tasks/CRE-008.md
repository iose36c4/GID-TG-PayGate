# [[CRE-008]] API Tokens: Crear, Rotar, Scopes (read:channels, write:webhooks), Expiración

## Descripción
Implementar gestión de API tokens para creadores: creación, rotación, scopes (read:channels, write:webhooks), expiración y revocación.

## Código de Ejemplo
```php
// app/Models/ApiToken.php
class ApiToken extends Model
{
    protected $fillable = [
        'channel_pago_id', 'name', 'token', 'scopes', 
        'expires_at', 'last_used_at', 'revoked_at',
    ];

    protected $casts = [
        'scopes' => 'array',
        'expires_at' => 'datetime',
        'last_used_at' => 'datetime',
        'revoked_at' => 'datetime',
    ]

    public function channel() { return $this->belongsTo(ChannelPago::class); }

    public function isValid(): bool
    {
        if ($this->revoked_at) return false;
        if ($this->expires_at && $this->expires_at->isPast()) return false;
        return true;
    }

    public function hasScope(string $scope): bool
    {
        return in_array($scope, $this->scopes ?? []);
    }

    public function markAsUsed(): void
    {
        $this->update(['last_used_at' => now()]);
    }
}
```

```php
// app/Domains/Creadores/Http/Controllers/ApiTokenController.php
namespace App\Domains\Creadores\Http\Controllers;

class ApiTokenController extends Controller
{
    public function index(ChannelPago $channel)
    {
        $this->authorize('manage', $channel);
        $tokens = $channel->apiTokens()->latest()->paginate(15);
        return view('domains.creadores.channels.api-tokens.index', compact('channel', 'tokens'));
    }

    public function store(ChannelPago $channel, ApiTokenStoreRequest $request)
    {
        $this->authorize('manage', $channel);

        $token = ApiToken::create([
            'channel_pago_id' => $channel->id,
            'name' => $request->name,
            'token' => Crypt::encryptString(Str::random(64)),
            'scopes' => $request->scopes,
            'expires_at' => $request->expires_at,
        ]);

        // Mostrar token plano solo una vez
        $plainToken = decrypt($token->token);
        
        return redirect()->back()->with([
            'success' => 'Token creado',
            'plain_token' => $plainToken, // Solo se muestra una vez
        ]);
    }

    public function rotate(ChannelPago $channel, ApiToken $token)
    {
        $this->authorize('manage', $token->channel);
        
        $newToken = $token->replicate();
        $token->update(['revoked_at' => now()]);
        
        $token->update([
            'token' => Crypt::encryptString(Str::random(64)),
            'revoked_at' => null,
        ]);

        $plainToken = decrypt($token->token);
        
        return redirect()->back()->with('success', 'Token rotado', 'plain_token' => $plainToken);
    }

    public function revoke(ChannelPago $channel, ApiToken $token)
    {
        $this->authorize('manage', $token->channel);
        $token->update(['revoked_at' => now()]);
        return back()->with('success', 'Token revocado');
    }
}
```

## Criterios de Aceptación
- [ ] Crear token: nombre, scopes (array), expiración opcional
- [ ] Token generado: 64 chars aleatorios, cifrado AES-256 en BD
- [ ] Token plano visible UNA sola vez al crear
- [ ] Scopes: read:channels, write:webhooks, read:analytics, write:channels
- [ ] Expiración opcional con fecha
- [ ] Rotar: genera nuevo, revoca anterior, muestra nuevo plano
- [ ] Revocar: soft delete (revoked_at), invalida inmediatamente
- [ ] Validación: scopes válidos, expiración futura, token no revocado
- [ ] Last used tracking: actualiza last_used_at en cada request

## Notas Técnicas
- Token almacenado: `Crypt::encryptString(Str::random(64))`
- Validación middleware: verifica scopes, expiración, revocación
- Header: `Authorization: Bearer <token>`
- Rate limiting por token: 1000 req/hora
- Scopes válidos: `read:channels`, `write:webhooks`, `read:analytics`, `write:channels`

# [[CRE-009]] Configuración: Marca Blanca (Logo, Colores, Dominio Personalizado v1.1), Notificaciones

## Descripción
Implementar configuración de marca blanca para creadores: logo, colores personalizados, dominio personalizado (v1.1), y preferencias de notificaciones.

## Código de Ejemplo
```php
// app/Models/ChannelBranding.php
class ChannelBranding extends Model
{
    protected $fillable = [
        'channel_pago_id',
        'logo_path',
        'favicon_path',
        'primary_color',
        'secondary_color',
        'custom_domain',
        'custom_domain_verified',
        'custom_domain_ssl',
        'email_notifications',
        'telegram_notifications',
        'in_app_notifications',
        'theme_mode', // light, dark, system
    ];

    protected $casts = [
        'custom_domain_verified' => 'boolean',
        'custom_domain_ssl' => 'boolean',
    ];

    public function channel()
    {
        return $this->belongsTo(ChannelPago::class);
    }
}
```

```php
// app/Domains/Creadores/Http/Controllers/BrandingController.php
namespace App\Domains\Creadores\Http\Controllers;

class BrandingController extends Controller
{
    public function index(ChannelPago $channel)
    {
        $this->authorize('manage', $channel);
        $branding = $channel->branding ?? $channel->branding()->create([]);
        return view('domains.creadores.channels.branding.index', compact('channel', 'branding'));
    }

    public function update(ChannelPago $channel, BrandingUpdateRequest $request)
    {
        $this->authorize('manage', $channel);
        
        $data = $request->validated();
        
        // Manejo de archivos
        if ($request->hasFile('logo')) {
            $path = $request->file('logo')->store('branding/logos', 'public');
            $data['logo_path'] = $path;
        }
        if ($request->hasFile('favicon')) {
            $path = $request->file('favicon')->store('branding/favicons', 'public');
            $data['favicon_path'] = $path;
        }

        $channel->branding()->updateOrCreate(
            ['channel_pago_id' => $channel->id],
            $data
        );

        // Si se cambió dominio personalizado, verificar SSL
        if ($request->filled('custom_domain') && $request->custom_domain !== $channel->branding?->custom_domain) {
            $this->queueDomainVerification($channel);
        }

        return redirect()->back()->with('success', 'Marca blanca actualizada');
    }

    private function queueDomainVerification(ChannelPago $channel)
    {
        \App\Jobs\VerifyCustomDomain::dispatch($channel->branding);
    }
}
```

## Criterios de Aceptación
- [ ] Logo: upload + preview, formatos SVG/PNG/WebP, max 2MB
- [ ] Favicon: upload .ico/.png, preview 32x32
- [ ] Colores: color picker + hex input, preview en vivo, CSS variables auto-update
- [ ] Dominio personalizado: input dominio, verificación DNS CNAME, SSL auto (Let's Encrypt), badge estado verificado
- [ ] Notificaciones: 4 toggles (email subs, email renovaciones, telegram retiros, in-app actividad)
- [ ] Tema: 3 opciones (Claro, Oscuro, Sistema), persiste en BD + localStorage
- [ ] Branding aplicado en: emails, checkout, dashboard, landing pública
- [ ] Preview en vivo de cambios de color/tema

## Notas Técnicas
- Archivos subidos a `storage/app/public/branding/`
- Colores guardados como hex, aplicados via CSS custom properties (`--color-primary`, `--color-secondary`)
- Dominio personalizado: verificación DNS CNAME + SSL automático (Let's Encrypt via acmephp)
- Notificaciones: guardadas en `branding.notifications` JSON column
- Tema: persistido en BD + localStorage para carga instantánea

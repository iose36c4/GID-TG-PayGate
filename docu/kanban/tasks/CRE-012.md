# [[CRE-012]] Ciclos de Cobro Creador: Frecuencia (5 días, 15 días, Mensual), Mínimo Retiro, Comisiones

## Descripción
Implementar configuración de ciclos de cobro para creadores: frecuencia de cobro (5 días, 15 días, mensual), monto mínimo de retiro, comisiones de plataforma y pasarela.

## Código de Ejemplo
```php
// app/Models/PayoutSchedule.php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class PayoutSchedule extends Model
{
    protected $fillable = [
        'channel_pago_id',
        'frequency', // '5_days', '15_days', 'monthly'
        'minimum_amount', // monto mínimo para solicitar retiro
        'platform_fee_percentage', // comisión plataforma (ej: 5%)
        'gateway_fee_percentage', // comisión pasarela (ej: 3.5% + IVA)
        'fixed_fee', // fee fijo por transacción (ej: $50 ARS)
        'currency',
        'is_active',
        'next_payout_at',
        'last_payout_at',
    ];

    protected $casts = [
        'platform_fee_percentage' => 'decimal:4',
        'gateway_fee_percentage' => 'decimal:4',
        'fixed_fee' => 'decimal:2',
        'minimum_amount' => 'decimal:2',
        'is_active' => 'boolean',
        'next_payout_at' => 'datetime',
        'last_payout_at' => 'datetime',
    ];

    public function channel()
    {
        return $this->belongsTo(ChannelPago::class);
    }

    public function calculateNetAmount(float $grossAmount): array
    {
        $platformFee = $grossAmount * $this->platform_fee_percentage;
        $gatewayFee = $grossAmount * $this->gateway_fee_percentage;
        $totalFees = $platformFee + $gatewayFee + $this->fixed_fee;
        $netAmount = $grossAmount - $totalFees;

        return [
            'gross' => $grossAmount,
            'platform_fee' => round($platformFee, 2),
            'gateway_fee' => round($gatewayFee, 2),
            'fixed_fee' => $this->fixed_fee,
            'total_fees' => round($totalFees, 2),
            'net' => max(0, round($netAmount, 2)),
        ];
    }

    public function canRequestPayout(float $availableBalance): bool
    {
        return $this->is_active && $availableBalance >= $this->minimum_amount;
    }

    public function getNextPayoutDate(): ?\Carbon\Carbon
    {
        if (!$this->last_payout_at) {
            return now()->addDays($this->getFrequencyDays());
        }

        return $this->last_payout_at->copy()->addDays($this->getFrequencyDays());
    }

    private function getFrequencyDays(): int
    {
        return match($this->frequency) {
            '5_days' => 5,
            '15_days' => 15,
            'monthly' => 30,
            default => 30,
        };
    }
}
```

```php
// app/Domains/Creadores/Http/Controllers/PayoutScheduleController.php
namespace App\Domains\Creadores\Http\Controllers;

use App\Models\{ChannelPago, PayoutSchedule};

class PayoutScheduleController extends Controller
{
    public function index(ChannelPago $channel)
    {
        $this->authorize('manage', $channel);
        $schedule = $channel->payoutSchedule ?? $channel->payoutSchedule()->create([
            'frequency' => 'monthly',
            'minimum_amount' => 1000, // $1000 ARS
            'platform_fee_percentage' => 0.05, // 5%
            'gateway_fee_percentage' => 0.035, // 3.5%
            'fixed_fee' => 50, // $50 ARS
            'currency' => 'ARS',
            'is_active' => true,
        ]);

        return view('domains.creadores.channels.payout-schedule.index', compact('channel', 'schedule'));
    }

    public function update(ChannelPago $channel, PayoutScheduleRequest $request)
    {
        $this->authorize('manage', $channel);
        
        $schedule = $channel->payoutSchedule()->updateOrCreate(
            ['channel_pago_id' => $channel->id],
            $request->validated()
        );

        // Recalcular próximo retiro
        $schedule->update([
            'next_payout_at' => $schedule->getNextPayoutDate(),
        ]);

        return redirect()->back()->with('success', 'Ciclo de cobro actualizado');
    }
}
```

## Criterios de Aceptación
- [ ] Frecuencia: 3 opciones (5 días, 15 días, mensual) con radio buttons visuales
- [ ] Monto mínimo retiro: input numérico, default $1000 ARS, mínimo $100
- [ ] Comisiones editables: Plataforma % (default 5%), Pasarela % (default 3.5%), Fee fijo (default $50 ARS)
- [ ] Simulador en tiempo real: input bruto → calcula neto, fees desglosados
- [ ] Validación: frecuencia activa, montos positivos, porcentajes 0-100%
- [ ] Job diario (Scheduler): verifica saldos >= mínimo, procesa retiros automáticos
- [ ] Próximo retiro: calculado dinámicamente según frecuencia y último retiro
- [ ] Historial de retiros con estado: pendiente, procesando, completado, fallido

## Notas Técnicas
- Job: `php artisan schedule:run` diario, comando `PayoutProcessor::run()`
- Cálculo neto: `Bruto - (Bruto * %Plataforma) - (Bruto * %Pasarela) - FeeFijo`
- Monto mínimo evita retiros muy chicos (costos fijos de transferencia)
- Fee fijo cubre costo transferencia bancaria (~$50-100 ARS)
- Comisiones configurables por canal, heredables de config global (ADM-013)
- Moneda configurable (default ARS), preparado para multi-moneda v1.1

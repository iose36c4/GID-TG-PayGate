# [[CRE-015]] Configuración Fiscal Creador: Tipo Contribuyente, IVA, Ganancias, IIBB, Domicilio Fiscal

## Descripción
Implementar configuración fiscal completa para creadores: tipo de contribuyente AFIP (RI, Monotributo, Exento, CF), IVA, Ganancias, IIBB por provincia, domicilio fiscal, CUIT/CUIL, certificado digital.

## Código de Ejemplo
```php
// app/Domains/Creadores/Http/Controllers/TaxConfigurationController.php
namespace App\Domains\Creadores\Http\Controllers;

use App\Models\{ChannelPago, User};
use App\Services\ArgentineTaxService;

class TaxConfigurationController extends Controller
{
    public function __construct(protected ArgentineTaxService $taxService) {}

    public function index(ChannelPago $channel)
    {
        $this->authorize('manage', $channel);
        $creator = $channel->owner;
        
        return view('domains.creadores.channels.tax-config.index', [
            'channel' => $channel,
            'creator' => $creator->load('taxConfiguration'),
            'taxpayerTypes' => ArgentineTaxService::TAXPAYER_TYPES,
            'provinces' => ArgentineTaxService::PROVINCES,
        ]);
    }

    public function update(ChannelPago $channel, TaxConfigRequest $request)
    {
        $this->authorize('manage', $channel);
        
        $creator = $channel->owner;
        $creator->update($request->validated([
            'taxpayer_type',      // responsable_inscripto, monotributo, exento, consumidor_final
            'cuit_cuil',          // 11 dígitos
            'tax_province',       // CABA, BA, CORDOBA, etc.
            'tax_address',        // Domicilio fiscal completo
            'tax_city',
            'tax_zip_code',
            'iibb_number',        // Número IIBB provincial
            'monotributo_category', // A-K (si monotributo)
            'ganancias_exempt',   // boolean - exento ganancias
            'iva_exempt',         // boolean - exento IVA
            'digital_certificate_path', // ruta certificado .crt
            'private_key_path',   // ruta clave privada .key
        ]));

        // Validar CUIT/CUIL algoritmo módulo 11
        if (!$this->taxService->validateCuitCuil($creator->cuit_cuil)) {
            return back()->withErrors(['cuit_cuil' => 'CUIT/CUIL inválido']);
        }

        return redirect()->back()->with('success', 'Configuración fiscal actualizada');
    }

    public function validateCuit(ChannelPago $channel, Request $request)
    {
        $valid = $this->taxService->validateCuitCuil($request->cuit_cuil);
        return response()->json(['valid' => $valid]);
    }

    public function fetchAfipData(ChannelPago $channel, Request $request)
    {
        // Consultar padrón AFIP/ARCA (WS SR Padrón A13)
        $afipService = app(\App\Services\AfipWsSrPadronService::class);
        $data = $afipService->queryPadron($request->cuit_cuil);
        
        return response()->json($data);
    }
}
```

```blade
<script>
function fetchAfipData() {
    const cuit = document.querySelector('input[name="cuit_cuil"]').value;
    if (cuit.length !== 11) return alert('CUIT debe tener 11 dígitos');
    
    const resultDiv = document.getElementById('afip-result');
    resultDiv.classList.remove('hidden');
    resultDiv.textContent = 'Consultando AFIP...';
    resultDiv.className = 'mt-2 text-sm';
    
    fetch('{{ route("creadores.channels.tax-config.fetch-afip") }}', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'X-CSRF-TOKEN': document.querySelector('meta[name="csrf-token"]').content
        },
        body: JSON.stringify({ cuit_cuil: cuit })
    })
    .then(r => r.json())
    .then(data => {
        if (data.success) {
            resultDiv.className = 'mt-2 text-sm text-success';
            resultDiv.innerHTML = `<strong>Datos AFIP:</strong> ${data.data.denominacion} - ${data.data.impuesto}`;
            // Auto-llenar campos
        } else {
            resultDiv.className = 'mt-2 text-sm text-error';
            resultDiv.textContent = 'Error: ' + (data.message || 'CUIT no encontrado');
        }
    })
    .catch(() => {
        resultDiv.className = 'mt-2 text-sm text-error';
        resultDiv.textContent = 'Error de conexión';
    });
}
</script>
```

## Criterios de Aceptación
- [ ] Tipo contribuyente: 4 opciones (RI, Monotributo, Exento, Consumidor Final) con radio cards visuales
- [ ] CUIT/CUIL: 11 dígitos, validación algoritmo Módulo 11, botón "Consultar AFIP" (WS SR Padrón A13)
- [ ] Domicilio fiscal: Provincia (24 opciones), Ciudad, CP (4 dígitos), Dirección completa
- [ ] IIBB: Número inscripción provincial, Categoría Monotributo A-K (select condicional)
- [ ] Exenciones: Checkboxes Ganancias (certificado), IVA (certificado)
- [ ] Certificado digital: Upload .crt + .key, validación OpenSSL, vigencia 1 año, alerta 30 días
- [ ] Validación CUIT/CUIL: Algoritmo Módulo 11 (dígito verificador)
- [ ] Consulta AFIP: WS SR Padrón A13 autocompleta datos (denominación, impuesto, domicilio)
- [ ] Almacenamiento encriptado: Certificado y clave privada con Laravel Crypt
- [ ] Alerta vencimiento certificado: 30 días antes (job diario + notificación)

## Notas Técnicas
- AFIP = ARCA (Agencia Recaudación Control Aduanero) desde 2024
- CUIT/CUIL: 11 dígitos (20/23/24/27 + 8 dígitos + dígito verificador Módulo 11)
- WS SR Padrón A13: `wswhomo.afip.gov.ar` (testing) / `servicios1.afip.gov.ar` (production)
- Certificado digital: .crt + .key OpenSSL 2048 bits, vigencia 1 año
- Almacenamiento: `Storage::disk('local')->put()` + `Crypt::encryptString()`
- IIBB: Alícuotas variables por provincia (CABA 3.5%, BA 3.5%, Córdoba 4.5%, etc.)
- Monotributo: Categorías A-K, recategorización semestral (enero/julio)
- Certificado AFIP: emitido por ARCA, vigencia 1 año, renovar 30 días antes

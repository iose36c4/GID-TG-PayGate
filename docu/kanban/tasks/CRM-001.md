# [[CRM-001]] Ticketing: Crear, Asignar, Estados (open, pending, waiting, closed), SLA Timers

## Descripción
Implementar sistema de ticketing completo en CRM: creación, asignación, gestión de estados con SLA timers automáticos.

## Código de Ejemplo
```php
// app/Models/Ticket.php
class Ticket extends Model
{
    protected $fillable = [
        'user_id', 'category_id', 'assigned_to', 'subject', 'description',
        'priority', 'status', 'channel_pago_id', 'sla_deadline',
        'closed_at', 'closed_by',
    ];

    protected $casts = [
        'priority' => 'string', // low, normal, high, urgent
        'status' => 'string', // open, pending, waiting, closed
        'sla_deadline' => 'datetime',
        'closed_at' => 'datetime',
    ];

    public function user() { return $this->belongsTo(User::class); }
    public function category() { return $this->belongsTo(TicketCategory::class); }
    public function assignee() { return $this->belongsTo(User::class, 'assigned_to'); }
    public function channel() { return $this->belongsTo(ChannelPago::class); }
    public function replies() { return $this->hasMany(TicketReply::class)->orderBy('created_at'); }
    public function attachments() { return $this->morphMany(Attachment::class, 'attachable'); }
    public function tags() { return $this->morphToMany(Tag::class, 'taggable'); }

    public function isOverdue(): bool
    {
        return $this->sla_deadline && $this->sla_deadline->isPast() && $this->status !== 'closed';
    }

    public function getSlaRemainingAttribute(): ?string
    {
        if (!$this->sla_deadline || $this->status === 'closed') return null;
        $diff = now()->diffForHumans($this->sla_deadline, true);
        return $this->sla_deadline->isPast() ? "Vencido hace {$diff}" : "En {$diff}";
    }
}
```

```php
// app/Domains/Staff/Http/Controllers/Crm/TicketController.php
namespace App\Domains\Staff\Http\Controllers\Crm;

class TicketController extends Controller
{
    public function index()
    {
        $tickets = Ticket::with(['user', 'category', 'assignee', 'channel'])
            ->when(request('status'), fn($q) => $q->where('status', request('status')))
            ->when(request('assignee_id'), fn($q) => $q->where('assigned_to', request('assignee_id')))
            ->when(request('priority'), fn($q) => $q->where('priority', request('priority')))
            ->latest()
            ->paginate(20);

        return view('domains.staff.crm.tickets.index', compact('tickets'));
    }

    public function store(TicketStoreRequest $request)
    {
        $ticket = Ticket::create([
            'user_id' => auth()->id(),
            'category_id' => $request->category_id,
            'subject' => $request->subject,
            'description' => $request->description,
            'priority' => $request->priority ?? 'normal',
            'status' => 'open',
            'channel_pago_id' => $request->channel_pago_id,
            'sla_deadline' => $this->calculateSlaDeadline($request->priority ?? 'normal'),
        ]);

        // Notificar staff asignado o canal #tickets
        app(\App\Services\TelegramService::class)->notifyStaffNewTicket($ticket);

        return redirect()->route('crm.tickets.show', $ticket)
            ->with('success', 'Ticket creado');
    }

    public function show(Ticket $ticket)
    {
        $this->authorize('view', $ticket);
        $ticket->load(['user', 'category', 'assignee', 'channel', 'replies.user', 'replies.attachments', 'tags']);
        return view('domains.staff.crm.tickets.show', compact('ticket'));
    }

    public function reply(Ticket $ticket, TicketReplyRequest $request)
    {
        $this->authorize('reply', $ticket);

        $reply = $ticket->replies()->create([
            'user_id' => auth()->id(),
            'message' => $request->message,
            'is_internal' => $request->boolean('is_internal'),
            'attachments' => $request->attachments ?? [],
        ]);

        // Actualizar SLA si es respuesta del cliente
        if (!$request->boolean('is_internal')) {
            $ticket->update(['sla_deadline' => $this->calculateSlaDeadline($ticket->priority)]);
        }

        // Notificar staff asignado
        app(\App\Services\TelegramService::class)->notifyStaffTicketReply($ticket, $reply);

        return back()->with('success', 'Respuesta enviada');
    }

    public function assign(Ticket $ticket, AssignTicketRequest $request)
    {
        $this->authorize('assign', $ticket);
        $ticket->update(['assigned_to' => $request->user_id]);
        return back()->with('success', 'Ticket asignado');
    }

    public function changeStatus(Ticket $ticket, StatusChangeRequest $request)
    {
        $this->authorize('changeStatus', $ticket);
        
        $oldStatus = $ticket->status;
        $newStatus = $request->status;
        
        $ticket->update([
            'status' => $newStatus,
            'closed_at' => $newStatus === 'closed' ? now() : null,
            'closed_by' => $newStatus === 'closed' ? auth()->id() : null,
        ]);

        // Log para auditoría
        \App\Models\AuditLog::create([
            'user_id' => auth()->id(),
            'action' => 'ticket_status_changed',
            'description' => "Ticket #{$ticket->id} estado: {$oldStatus} → {$newStatus}",
        ]);

        return back()->with('success', "Estado cambiado a: {$newStatus}");
    }

    private function calculateSlaDeadline(string $priority): ?Carbon
    {
        return match($priority) {
            'urgent' => now()->addHours(2),
            'high' => now()->addHours(8),
            'normal' => now()->addHours(24),
            'low' => now()->addHours(72),
            default => now()->addHours(24),
        };
    }
}
```

## Criterios de Aceptación
- [ ] Crear ticket: categoría, prioridad, asunto, descripción, adjuntos
- [ ] Listado con filtros: estado, prioridad, asignado, búsqueda
- [ ] Tabla: asunto, categoría, prioridad (badge), estado (badge), asignado, SLA (countdown), última actividad
- [ ] Detalle: historial cronológico mensajes, responder, adjuntos, notas internas
- [ ] Estados: open, pending, waiting, closed con badges de color
- [ ] Prioridades: low, normal, high, urgent con badges de color
- [ ] SLA timers: cuenta regresiva visual, alerta si vencido (rojo)
- [ ] Asignación a staff, cambio prioridad, cambio estado
- [ ] Notificaciones: Telegram/Email a staff en nuevo ticket y respuestas
- [ ] SLA auto-cálculo: urgent=2h, high=8h, normal=24h, low=72h
- [ ] Auto-escalation opcional si SLA vencido

## Notas Técnicas
- SLA deadline calculado al crear + actualizar en cada respuesta cliente
- Timer visual con JS: actualiza cada minuto
- Overdue: background rojo suave en fila tabla
- Notificaciones: Queue job para Telegram/Email
- SLA breach: job diario revisa vencidos, escala a supervisor

# [[CRM-002]] Colas: Sin Asignar, Mis Tickets, Equipo, Escalados, Vencidos

## Descripción
Implementar sistema de colas de tickets en CRM: vistas predefinidas para organizar el trabajo del equipo de soporte.

## Código de Ejemplo
```php
// app/Domains/Staff/Http/Controllers/Crm/TicketQueueController.php
namespace App\Domains\Staff\Http\Controllers\Crm;

class TicketQueueController extends Controller
{
    public function unassigned()
    {
        $tickets = Ticket::whereNull('assigned_to')
            ->where('status', 'open')
            ->with(['user', 'category'])
            ->latest()
            ->paginate(20);

        return view('domains.staff.crm.tickets.queue', [
            'tickets' => $tickets,
            'queueName' => 'Sin Asignar',
            'queueIcon' => 'user-minus',
            'queueColor' => 'warning',
        ]);
    }

    public function mine()
    {
        $tickets = Ticket::where('assigned_to', auth()->id())
            ->whereIn('status', ['open', 'pending', 'waiting'])
            ->with(['user', 'category'])
            ->latest()
            ->paginate(20);

        return view('domains.staff.crm.tickets.queue', [
            'tickets' => $tickets,
            'queueName' => 'Mis Tickets',
            'queueIcon' => 'user',
            'queueColor' => 'info',
        ]);
    }

    public function team()
    {
        $tickets = Ticket::whereHas('assignee', fn($q) => $q->whereIn('role', ['staff', 'admin']))
            ->whereIn('status', ['open', 'pending', 'waiting'])
            ->with(['user', 'category', 'assignee'])
            ->latest()
            ->paginate(20);

        return view('domains.staff.crm.tickets.queue', [
            'tickets' => $tickets,
            'queueName' => 'Equipo',
            'queueIcon' => 'users',
            'queueColor' => 'success',
        ]);
    }

    public function escalated()
    {
        $tickets = Ticket::where('status', '!=', 'closed')
            ->where('priority', 'urgent')
            ->orWhere(function($q) {
                $q->where('sla_deadline', '<', now())
                  ->where('status', '!=', 'closed');
            })
            ->with(['user', 'category', 'assignee'])
            ->latest()
            ->paginate(20);

        return view('domains.staff.crm.tickets.queue', [
            'tickets' => $tickets,
            'queueName' => 'Escalados',
            'queueIcon' => 'alert-triangle',
            'queueColor' => 'error',
        ]);
    }

    public function overdue()
    {
        $tickets = Ticket::where('status', '!=', 'closed')
            ->where('sla_deadline', '<', now())
            ->with(['user', 'category', 'assignee'])
            ->latest()
            ->paginate(20);

        return view('domains.staff.crm.tickets.queue', [
            'tickets' => $tickets,
            'queueName' => 'Vencidos',
            'queueIcon' => 'alert-circle',
            'queueColor' => 'error',
        ]);
    }
}
```

```mermaid
    C[Escalados] --> C1[Prioridad=urgent OR SLA vencido]

    D[Vencidos] --> D1[SLA deadline < now() AND status!=closed]
    D --> D2[Orden: más antiguo primero]
```

## Criterios de Aceptación
- [ ] 5 colas predefinidas accesibles via tabs/pestañas
- [ ] Sin Asignar: tickets open sin assigned_to, orden prioridad+fecha
- [ ] Mis Tickets: asignados a usuario actual, excluye cerrados
- [ ] Equipo: todos los tickets del equipo (staff/admin)
- [ ] Escalados: prioridad urgent O SLA vencido
- [ ] Vencidos: SLA deadline pasado, status != closed
- [ ] Tabs navegables, contador de tickets por cola
- [ ] Filtros adicionales dentro de cada cola (prioridad, categoría)
- [ ] Acciones rápidas: asignar a mí, cambiar prioridad, ver detalle

## Notas Técnicas
- Rutas nombradas: `crm.tickets.queue.{unassigned,mine,team,escalated,overdue}`
- Vista compartida `queue.blade.php` con props: queueName, queueIcon, queueColor
- Scopes en modelo Ticket: `scopeUnassigned`, `scopeMine`, `scopeTeam`, `scopeEscalated`, `scopeOverdue`
- Contadores en tabs: badge con total por cola
- Auto-refresh opcional (polling 30s) para colas activas

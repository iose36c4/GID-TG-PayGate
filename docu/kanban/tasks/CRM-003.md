# [[CRM-003]] Respuestas: Macros/Canned Replies, Adjuntos, Internal Notes, Time Tracking

## Descripción
Implementar sistema de respuestas en tickets: macros/canned replies, adjuntos, notas internas, time tracking para medir tiempo de resolución.

## Código de Ejemplo
```php
// app/Models/TicketReply.php
class TicketReply extends Model
{
    protected $fillable = [
        'ticket_id', 'user_id', 'message', 'is_internal', 'attachments',
        'time_spent_minutes', 'macro_id',
    ];

    protected $casts = [
        'is_internal' => 'boolean',
        'attachments' => 'array',
        'time_spent_minutes' => 'integer',
    ];

    public function ticket() { return $this->belongsTo(Ticket::class); }
    public function user() { return $this->belongsTo(User::class); }
    public function macro() { return $this->belongsTo(Macro::class); }
    public function attachments() { return $this->morphMany(Attachment::class, 'attachable'); }
}
```

```php
// app/Models/Macro.php
class Macro extends Model
{
    protected $fillable = [
        'name', 'content', 'category_id', 'is_public', 'created_by',
    ];

    protected $casts = [
        'is_public' => 'boolean',
    ];

    public function category() { return $this->belongsTo(MacroCategory::class); }
    public function creator() { return $this->belongsTo(User::class, 'created_by'); }
    public function usages() { return $this->hasMany(TicketReply::class, 'macro_id'); }
}
```

```php
// app/Domains/Staff/Http/Controllers/Crm/TicketReplyController.php
class TicketReplyController extends Controller
{
    public function store(Ticket $ticket, ReplyStoreRequest $request)
    {
        $this->authorize('reply', $ticket);

        $reply = $ticket->replies()->create([
            'user_id' => auth()->id(),
            'message' => $request->message,
            'is_internal' => $request->boolean('is_internal'),
            'attachments' => $request->attachments ?? [],
            'time_spent_minutes' => $request->time_spent_minutes,
            'macro_id' => $request->macro_id,
        ]);

        // Actualizar SLA si es respuesta del cliente
        if (!$request->boolean('is_internal')) {
            $ticket->update(['sla_deadline' => $this->calculateSlaDeadline($ticket->priority)]);
        }

        // Notificar staff asignado
        app(\App\Services\TelegramService::class)->notifyStaffTicketReply($ticket, $reply);

        return back()->with('success', 'Respuesta enviada');
    }

    public function storeInternalNote(Ticket $ticket, InternalNoteRequest $request)
    {
        $this->authorize('addInternalNote', $ticket);

        $reply = $ticket->replies()->create([
            'user_id' => auth()->id(),
            'message' => $request->message,
            'is_internal' => true,
            'attachments' => $request->attachments ?? [],
        ]);

        return response()->json(['reply' => $reply]);
    }
}
```

## Criterios de Aceptación
- [ ] Macros: CRUD categorías, variables dinámicas, shortcuts teclado
- [ ] Respuesta: textarea + macros dropdown + checkbox nota interna + time tracking
- [ ] Adjuntos: drag & drop, paste image, preview, max 10MB, tipos permitidos
- [ ] Notas internas: checkbox, badge visible, no notifica cliente
- [ ] Time tracking: input min + checkbox facturable, suma en sidebar
- [ ] Shortcuts teclado: Ctrl+Enter enviar, Tab macro, Ctrl+Shift+N nota interna
- [ ] Macros públicas/privadas, categorías, uso tracking

## Notas Técnicas
- Macros con variables: `{{ticket_id}}`, `{{user_name}}`, `{{channel_name}}`
- Adjuntos: max 10MB, tipos: imagen, pdf, doc, txt, código
- Shortcuts: Ctrl+Enter enviar, Tab siguiente macro, Ctrl+Shift+N nota interna
- Time tracking: suma en sidebar, reporte por staff/ticket
- Macros: públicas (equipo) / privadas (usuario)

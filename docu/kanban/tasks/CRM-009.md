# [[CRM-009]] Integración Telegram: Notificaciones Ticket en Grupo Staff, Comandos Bot

## Descripción
Implementar integración completa con Telegram en CRM: notificaciones de tickets en grupo staff, comandos de bot para gestión rápida, botones interactivos.

## Código de Ejemplo
```php
// app/Services/TelegramService.php
namespace App\Services;

use Illuminate\Support\Facades\Http;
use Illuminate\Support\Facades\Log;

class TelegramService
{
    public function __construct(
        protected string $botToken = null,
        protected string $staffGroupId = null,
        protected string $adminBotToken = null
    ) {
        $this->botToken = $botToken ?? config('telegram.bot_token');
        $this->staffGroupId = $staffGroupId ?? config('telegram.staff_group_id');
        $this->adminBotToken = $adminBotToken ?? config('telegram.admin_bot_token');
    }

    public function sendMessage(string $chatId, string $text, array $options = []): bool
    {
        $response = Http::post("https://api.telegram.org/bot{$this->botToken}/sendMessage", array_merge([
            'chat_id' => $chatId,
            'text' => $text,
            'parse_mode' => 'HTML',
            'disable_web_page_preview' => true,
        ], $options));

        if (!$response->successful()) {
            Log::warning('Telegram sendMessage failed', [
                'chat_id' => $chatId,
                'response' => $response->json(),
            ]);
            return false;
        }
        return true;
    }

    public function sendMessageWithButtons(string $chatId, string $text, array $buttons): bool
    {
        $replyMarkup = [
            'inline_keyboard' => array_chunk($buttons, 2),
        ];

        return $this->sendMessage($chatId, $text, [
            'reply_markup' => json_encode($replyMarkup),
        ]);
    }

    public function notifyStaffNewTicket(Ticket $ticket): void
    {
        $text = "🎫 <b>Nuevo Ticket</b>\n\n" .
                "<b>Asunto:</b> {$ticket->subject}\n" .
                "<b>Prioridad:</b> {$ticket->priority}\n" .
                "<b>Categoría:</b> {$ticket->category->name}\n" .
                "<b>Cliente:</b> {$ticket->user->name} ({$ticket->user->email})";

        $buttons = [
            ['text' => '👁 Ver Ticket', 'url' => route('crm.tickets.show', $ticket)],
            ['text' => '✅ Asignarme', 'callback_data' => "assign_{$ticket->id}"],
            ['text' => '🏷 Asignar a...', 'callback_data' => "assign_menu_{$ticket->id}"],
        ];

        $this->sendMessageWithButtons($this->staffGroupId, $text, $buttons);
    }

    public function notifyStaffTicketReply(Ticket $ticket, TicketReply $reply): void
    {
        if (!$reply->is_internal) {
            $text = "💬 <b>Nueva respuesta en ticket</b>\n\n" .
                    "<b>Ticket:</b> {$ticket->subject}\n" .
                    "<b>De:</b> {$reply->user->name}\n" .
                    "<b>Mensaje:</b> {$reply->message}";

            $buttons = [
                ['text' => '👁 Ver', 'url' => route('crm.tickets.show', $reply->ticket_id)],
                ['text' => '✍️ Responder', 'callback_data' => "reply_{$ticket->id}"],
            ];

            $this->sendMessageWithButtons($this->staffGroupId, $text, $buttons);
        }
    }

    public function notifyStaffNewSubscription(Subscription $subscription): void
    {
        $text = "🎉 <b>Nueva suscripción</b>\n\n" .
                "Canal: <b>{$subscription->channel->name}</b>\n" .
                "Usuario: {$subscription->user->name}\n" .
                "Monto: {$subscription->price} {$subscription->currency}";

        $this->sendMessage($this->staffGroupId, $text);
    }

    public function handleCallbackQuery(array $update): void
    {
        $callbackQuery = $update['callback_query'];
        $data = $callbackQuery['data'];
        $chatId = $callbackQuery['message']['chat']['id'];
        $messageId = $callbackQuery['message']['message_id'];
        $userId = $callbackQuery['from']['id'];

        if (str_starts_with($data, 'assign_')) {
            $ticketId = explode('_', $data)[1];
            $this->handleAssignTicket($callbackQuery, $ticketId);
        } elseif (str_starts_with($data, 'assign_menu_')) {
            $ticketId = explode('_', $data)[2];
            $this->showAssignMenu($callbackQuery, $ticketId);
        } elseif (str_starts_with($data, 'reply_')) {
            $ticketId = explode('_', $data)[1];
            $this->promptReply($callbackQuery, $ticketId);
        } elseif (str_starts_with($data, 'close_')) {
            $ticketId = explode('_', $data)[1];
            $this->closeTicket($callbackQuery, $ticketId);
        } elseif (str_starts_with($data, 'priority_')) {
            [$_, $ticketId, $priority] = explode('_', $data);
            $this->changePriority($callbackQuery, $ticketId, $priority);
        }
    }

    private function handleAssignTicket($callbackQuery, int $ticketId): void
    {
        $ticket = Ticket::findOrFail($ticketId);
        $userId = $callbackQuery['from']['id'];

        $staff = User::where('telegram_id', $userId)->whereIn('role', ['staff', 'admin'])->first();
        
        if (!$staff) {
            $this->answerCallbackQuery($callbackQuery['id'], '❌ No estás autorizado');
            return;
        }

        $ticket->update(['assigned_to' => $staff->id]);
        
        $this->editMessageText($callbackQuery, "✅ Ticket asignado a <b>{$staff->name}</b>");
        $this->notifyTicketAssigned($ticket, $staff);
    }

    public function sendTicketCard(int $chatId, Ticket $ticket): void
    $text = "🎫 <b>{$ticket->subject}</b>\n\n" .
            "📂 {$ticket->category->name} | {$ticket->priority}\n" .
            "👤 {$ticket->user->name} | {$ticket->status}\n" .
            "⏰ SLA: {$ticket->sla_remaining}";

    $buttons = [
        ['text' => '👁 Ver', 'url' => route('crm.tickets.show', $ticket->id)],
        ['text' => '✅ Tomar', 'callback_data' => "assign_{$ticket->id}"],
        ['text' => '🏷 Tag', 'callback_data' => "tag_{$ticket->id}"],
    ];

    $this->sendMessageWithButtons($chatId, $text, $buttons);
}
```

```php
// app/Http/Controllers/TelegramWebhookController.php
class TelegramWebhookController extends Controller
{
    public function handle(Request $request)
    {
        $update = $request->all();
        
        if (isset($update['message'])) {
            $this->handleMessage($update['message']);
        } elseif (isset($update['callback_query'])) {
            app(\App\Services\TelegramService::class)->handleCallbackQuery($update['callback_query']);
        }

        return response()->json(['ok' => true]);
    }

    private function handleMessage(array $message): void
    {
        $text = $message['text'] ?? '';
        $chatId = $message['chat']['id'];
        $userId = $message['from']['id'];

        if (str_starts_with($text, '/')) {
            $this->handleCommand($chatId, $userId, $text);
        }
    }

    private function handleCommand(int $chatId, int $userId, string $command): void
    {
        $parts = explode(' ', $command, 2);
        $cmd = $parts[0];
        $args = $parts[1] ?? '';

        $staff = User::where('telegram_id', $userId)->whereIn('role', ['staff', 'admin'])->first();
        
        if (!$staff) {
            $this->telegram->sendMessage($chatId, '❌ No estás autorizado para usar este bot');
            return;
        }

        match($cmd) {
            '/tickets' => $this->sendMyTickets($chatId, $staff),
            '/unassigned' => $this->sendUnassignedTickets($chatId),
            '/mytickets' => $this->sendMyTickets($chatId, $staff),
            '/search' => $this->searchTickets($chatId, $staff, $args),
            '/help' => $this->sendHelp($chatId),
            default => $this->telegram->sendMessage($chatId, 'Comando no reconocido. Usa /help'),
        };
    }
}
```

## Criterios de Aceptación
- [ ] Notificaciones en grupo staff: nuevo ticket, respuesta, nueva suscripción, pago
- [ ] Botones interactivos: Ver, Asignarme, Asignar a..., Responder, Cerrar
- [ ] Comandos bot: /tickets, /unassigned, /mytickets, /search, /help
- [ ] Callbacks: assign_ticket_id, assign_menu, reply_ticket_id, close_ticket_id, priority_ticket_id_priority
- [ ] Auto-asignación: click "Asignarme" asigna al staff que clickeó
- [ ] Menú asignar: lista staff disponible con botones
- [ ] Respuesta rápida: botón responder abre modal/inline
- [ ] Cerrar ticket: botón cerrar + confirmación
- [ ] Cambio prioridad: botones low/normal/high/urgent
- [ ] Webhook: POST /telegram/webhook, validación token, procesa message + callback_query
- [ ] Seguridad: solo staff/admin autorizados, verificación user_id

## Notas Técnicas
- Bot token en config: `telegram.bot_token`, `telegram.admin_bot_token`, `telegram.staff_group_id`
- Webhook URL: `https://dominio.com/telegram/webhook` (setWebhook)
- Callbacks: `callback_data` con formato `action_ticketId_param`
- Rate limiting: 30 msg/s por bot (límite Telegram)
- Markdown/HTML parse_mode para formateo
- Inline keyboards para botones interactivos
- Rate limiting: 30 req/s por bot

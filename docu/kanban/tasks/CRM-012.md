# [[CRM-012]] Facturación desde CRM: Generar Factura A/B/C, CAE, Envío Email, Descarga PDF

## Descripción
Implementar facturación directa desde CRM: generar facturas A/B/C según tipo de cliente, solicitar CAE a AFIP/ARCA, generar PDF, envío por email, descarga.

## Código de Ejemplo
```php
// app/Domains/Staff/Http/Controllers/Crm/BillingController.php
namespace App\Domains\Staff\Http\Controllers\Crm;

class BillingController extends Controller
{
    public function __construct(protected ClientBillingService $billing) {}

    public function index()
    {
        $invoices = Invoice::with(['client', 'channel'])
            ->when(request('status'), fn($q) => $q->where('status', request('status')))
            ->when(request('date_from'), fn($q) => $q->whereDate('created_at', '>=', request('date_from')))
            ->when(request('date_to'), fn($q) => $q->whereDate('created_at', '<=', request('date_to')))
            ->latest()
            ->paginate(20);

        return view('domains.staff.crm.billing.index', compact('invoices'));
    }

    public function create()
    {
        $clients = User::where('role', 'user')->get();
        $channels = ChannelPago::where('status', 'active')->get();
        return view('domains.staff.crm.billing.create', compact('clients', 'channels'));
    }

    public function store(BillingStoreRequest $request)
    {
        $invoice = $this->billing->createInvoice($request->validated());
        return redirect()->route('crm.billing.show', $invoice)
            ->with('success', 'Factura creada');
    }

    public function show(Invoice $invoice)
    {
        $invoice->load(['client', 'channel', 'payments']);
        return view('domains.staff.crm.billing.show', compact('invoice'));
    }

    public function download(Invoice $invoice)
    {
        if (!$invoice->pdf_path || !Storage::disk('local')->exists($invoice->pdf_path)) {
            abort(404, 'PDF no disponible');
        }
        return Storage::disk('local')->download($invoice->pdf_path, "factura-{$invoice->number}.pdf");
    }

    public function resend(Invoice $invoice)
    {
        if ($invoice->status !== 'authorized') {
            return back()->with('error', 'Solo facturas autorizadas pueden reenviarse');
        }

        $this->billing->sendInvoiceEmail($invoice);
        return back()->with('success', 'Factura reenviada');
    }

    public function sendCAE(Invoice $invoice)
    {
        if ($invoice->status === 'rejected') {
            $result = app(\App\Services\AfipWsfeService::class)->authorizeInvoice($invoice);
            return response()->json($result);
        }
        return back()->with('error', 'Solo facturas rechazadas pueden reenviarse a AFIP');
    }
}
```

```blade
    if (confirm('¿Reenviar solicitud CAE a AFIP?')) {

            .then(data => alert(data.message));

}
```

## Criterios de Aceptación
- [ ] Listado facturas con filtros: estado (authorized/rejected/draft), fechas
- [ ] Tabla: número, fecha, cliente, tipo (badge A/B/E), total, estado (badge), CAE
- [ ] Crear factura: cliente + canal, conceptos, cálculo impuestos, envío CAE automático
- [ ] Detalle: PDF embebido, datos emisor/receptor, detalle items, totales, CAE, QR AFIP
- [ ] Descarga PDF directo
- [ ] Reenviar CAE: solo facturas rejected, reintento AFIP
- [ ] Reenviar email: botón en detalle y listado
- [ ] Permisos: policy BillingPolicy (view, create, manage)

## Notas Técnicas
- Usa ClientBillingService (compartido con CRE-013)
- PDF generado con DomPDF, QR AFIP + PDF417
- Reintento CAE: job con 3 reintentos, backoff exponencial
- PDF almacenado en storage/app/invoices/
- Permisos: policy BillingPolicy

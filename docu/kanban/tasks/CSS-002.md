# [[CSS-002]] Design Tokens: Implementación CSS Custom Properties desde Style Dictionary

## Descripción
Implementar generación automática de CSS Custom Properties desde tokens JSON usando Style Dictionary. Tokens: color (escalas + semánticos), spacing, typography, borderRadius, shadow, zIndex, breakpoints, transition.

```javascript
// style-dictionary.config.js (configuración extendida)
const { transform } = require('style-dictionary');

module.exports = {
  source: ['tokens/**/*.json'],
  platforms: {
    css: {
      transformGroup: 'css',
      buildPath: 'resources/css/tokens/',
      files: [{
        destination: '_tokens.css',
        format: 'css/variables',
        options: {
          outputReferences: true,
          selector: ':root',
        },
      }],
    },
    php: {
      transformGroup: 'php',
      buildPath: 'config/',
      files: [{
        destination: 'design-tokens.php',
        format: 'php/array',
      }],
    },
  },
};
```

## Cálculos y Algoritmos (LaTeX)
### Conversión Token → CSS Variable
$$
\text{CSS\_Var}(token) = \text{--} + \text{prefix} + \text{-} + \text{kebab-case(category)} + \text{-} + \text{kebab-case(name)} + \text{:} + \text{value}
$$

**Ejemplo:** `color.accent.400` → `--tgp-color-accent-400: #82b7c3;`

### Dark Mode Semantic Swap
$$
\text{semantic}_{dark} = \text{map}(\text{semantic}_{light}, \text{dark\_palette})
$$
No duplicar componentes, solo intercambiar tokens semánticos.

## Criterios de Aceptación
- [ ] Style Dictionary configurado y generando `_tokens.css` automáticamente
- [ ] 60+ CSS custom properties generadas (color, spacing, typography, radius, shadow, z-index, breakpoints, transitions)
- [ ] Prefijo configurable `--tgp-` (via `CSS_FRAMEWORK_PREFIX` env)
- [ ] Dark mode via `[data-theme="dark"]` override solo tokens semánticos
- [ ] PHP config generado para uso en Blade: `config('design-tokens.color.accent.400')`
- [ ] Referencias entre tokens funcionan (`{color.accent.400}`)
- [ ] Build integrado en Vite (plugin `build-tokens`)
- [ ] Source maps preservan nombres de tokens originales

## Notas Técnicas
- Style Dictionary v3+ para mejor TypeScript support
- `outputReferences: true` para resolver referencias `{color.accent.400}`
- Selector `:root` para light mode default, `[data-theme="dark"]` para dark
- No generar clases utilitarias aquí (eso es CSS-022 a CSS-030)
- Tokens semánticos referencian base tokens: `--tgp-color-accent-primary: var(--tgp-color-accent-400)`

# [[CSS-032]] RTL Support: Logical Properties, Direction, Mirroring Automático

## Descripción
Implementar soporte RTL (Right-to-Left): logical properties, dirección, mirroring automático para futuras expansiones a idiomas RTL (árabe, hebreo).

## Código de Ejemplo
```css
/* resources/css/utilities/_rtl.css */

/* Logical Properties - reemplazo de physical properties */
.container {
  margin-inline-start: auto;
  margin-inline-end: auto;
  padding-inline: var(--tgp-spacing-4);
}

.card {
  margin-block: var(--tgp-spacing-4);
  padding-inline: var(--tgp-spacing-4);
  border-inline-start: 1px solid var(--tgp-color-border-primary);
}

.sidebar {
  inset-inline-start: 0;
  inset-block: 0;
  border-inline-end: 1px solid var(--tgp-color-border-primary);
}

/* Logical equivalents mapping */
/* 
  margin-left    -> margin-inline-start
  margin-right   -> margin-inline-end
  padding-left   -> padding-inline-start
  padding-right  -> padding-inline-end
  border-left    -> border-inline-start
  border-right   -> border-inline-end
  left           -> inset-inline-start
  right          -> inset-inline-end
  text-align: left  -> text-align: start
  text-align: right -> text-align: end
  float: left    -> float: inline-start
  float: right   -> float: inline-end
  clear: left    -> clear: inline-start
  clear: right   -> clear: inline-end
*/

/* Direction utilities */
.dir-ltr { direction: ltr; }
.dir-rtl { direction: rtl; }

/* Auto direction based on lang */
[dir="rtl"] {
  /* Auto-mirroring para logical properties */
}

/* RTL-specific adjustments */
[dir="rtl"] .sidebar {
  /* Se posiciona a la derecha automáticamente con inset-inline-start */
}

[dir="rtl"] .breadcrumb__item:not(:last-child)::after {
  content: var(--breadcrumb-separator, "/");
  margin-inline-end: var(--tgp-spacing-2); /* era margin-left */
}

/* Icon mirroring para RTL */
[dir="rtl"] .icon-mirror {
  transform: scaleX(-1);
}

/* Utilidades direction */
.ltr { direction: ltr; }
.rtl { direction: rtl; }

@media (min-width: 640px) {
  .sm\:ltr { direction: ltr; }
  .sm\:rtl { direction: rtl; }
}
@media (min-width: 768px) {
  .md\:ltr { direction: ltr; }
  .md\:rtl { direction: rtl; }
}
@media (min-width: 1024px) {
  .lg\:ltr { direction: ltr; }
  .lg\:rtl { direction: rtl; }
}
@media (min-width: 1280px) {
  .xl\:ltr { direction: ltr; }
  .xl\:rtl { direction: rtl; }
}
```

```html
<!-- Uso en HTML -->
<html lang="ar" dir="rtl" data-theme="light">
<head>
  <!-- CSS usa logical properties, se adapta automáticamente -->
</head>
<body>
  <div class="container">
    <aside class="sidebar">...</aside> <!-- Se posiciona a la derecha -->
    <main>...</main>
  </div>
</body>
</html>
```

## Criterios de Aceptación
- [ ] Logical properties implementadas (margin/padding/border/inset inline-start/end)
- [ ] Direction utilities: .ltr, .rtl + responsive
- [ ] Auto mirroring: componentes se adaptan sin CSS extra
- [ ] Icon mirroring: .icon-mirror con scaleX(-1)
- [ ] HTML dir attribute maneja dirección global
- [ ] Responsive: sm:, md:, lg:, xl: prefixes
- [ ] Documentado en `docu/especificaciones/css-rtl-support.md`

## Notas Técnicas
- Logical properties: soporte nativo 95%+ navegadores modernos
- No requiere CSS separado para RTL - logical properties manejan mirroring
- `dir="rtl"` en `<html>` o contenedor padre
- `text-align: start/end` reemplaza left/right
- `float: inline-start/end` reemplaza left/right
- Icon mirroring solo para iconos direccionales (flechas, chevrons)
- Evaluar `writing-mode` para vertical text en v1.1

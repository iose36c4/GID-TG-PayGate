# [[CSS-034]] Build System: Vite Config, PostCSS (autoprefixer, cssnano), PurgeCSS, Sourcemaps, Hash Filenames

## Descripción
Configurar build system completo con Vite: PostCSS pipeline (autoprefixer, cssnano), PurgeCSS para producción, sourcemaps, hash filenames, code splitting.

## Código de Ejemplo
```javascript
// vite.config.js
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';
import postcss from 'postcss';
import autoprefixer from 'autoprefixer';
import cssnano from 'cssnano';
import postcssNested from 'postcss-nested';
import postcssImport from 'postcss-import';
import purgecss from '@fullhuman/postcss-purgecss';
import styleDictionary from 'style-dictionary';

export default defineConfig(({ mode }) => {
  const isProduction = mode === 'production';
  
  return {
    plugins: [
      laravel({
        input: [
          'resources/css/app.css',
          'resources/css/framework.css',
          'resources/js/app.js'
        ],
        refresh: true,
      }),
      {
        name: 'build-tokens',
        buildStart() {
          const sd = styleDictionary.extend({
            source: ['tokens/**/*.json'],
            platforms: {
              css: {
                transformGroup: 'css',
                buildPath: 'resources/css/tokens/',
                files: [{
                  destination: '_tokens.css',
                  format: 'css/variables',
                  options: { outputReferences: true },
                }],
              },
              php: {
                transformGroup: 'php',
                buildPath: 'config/',
                files: [{
                  destination: 'design-tokens.php',
                  format: 'php/array',
                }],
              },
            },
          });
          sd.buildAllPlatforms();
        },
      },
    ],
    css: {
      postcss: {
        plugins: [
          postcssImport(),
          postcssNested(),
          autoprefixer({
            grid: 'autoplace',
            flexbox: 'no-2009',
          }),
          ...(isProduction ? [
            cssnano({
              preset: ['default', {
                discardComments: { removeAll: true },
                normalizeWhitespace: true,
                minifyFontValues: true,
                minifyGradients: true,
                minifyParams: true,
                minifySelectors: true,
                reduceIdents: false,
                zindex: false,
              }],
            }),
            purgecss({
              content: [
                './resources/views/**/*.blade.php',
                './resources/js/**/*.js',
                './resources/js/**/*.vue',
              ],
              safelist: [
                /^sr-only$/,
                /^aria-/,
                /^data-/,
                /^animate-/,
                /^transition-/,
                /^duration-/,
                /^ease-/,
                /^delay-/,
                /^ring-/,
                /^shadow-/,
                /^focus-/,
                /^hover:/,
                /^focus:/,
                /^active:/,
                /^disabled:/,
                /^group-hover:/,
                /^peer-/,
                /^dark:/,
                /^sm:/,
                /^md:/,
                /^lg:/,
                /^xl:/,
                /^2xl:/,
                /^rtl/,
                /^ltr/,
                /^dir-/,
                /^html/,
                /^body/,
              ],
              keyframes: true,
              variables: true,
            }),
          ] : []),
        ],
      },
    },
    build: {
      cssCodeSplit: true,
      sourcemap: true,
      minify: isProduction ? 'cssnano' : false,
      rollupOptions: {
        output: {
          entryFileNames: 'assets/[name]-[hash].js',
          chunkFileNames: 'assets/[name]-[hash].js',
          assetFileNames: (assetInfo) => {
            const info = assetInfo.name.split('.');
            const ext = info[info.length - 1];
            if (/\.(png|jpe?g|gif|svg|webp|avif|woff2?|ttf|eot)$/.test(assetInfo.name)) {
              return `assets/media/[name]-[hash].${ext}`;
            }
            if (ext === 'css') {
              return `assets/css/[name]-[hash].${ext}`;
            }
            return `assets/[name]-[hash].${ext}`;
          },
        },
      },
    },
    server: {
      hmr: { host: 'localhost' },
    },
  };
});
```

## Criterios de Aceptación
- [ ] Vite configurado con laravel-vite-plugin
- [ ] Style Dictionary genera CSS variables + PHP config desde tokens JSON
- [ ] PostCSS pipeline: import, nested, autoprefixer, cssnano, purgecss
- [ ] Build genera: framework.css, framework.css.map, hashed filenames
- [ ] Tree-shaking / PurgeCSS configurado para producción con safelist completa
- [ ] Source maps habilitados para desarrollo
- [ ] CSS code splitting habilitado
- [ ] Naming convention: `--tgp-` prefix (configurable via CSS_FRAMEWORK_PREFIX)
- [ ] Scripts npm: dev, build, build:prod, tokens:build, tokens:watch
- [ ] Documentado en `docu/especificaciones/css-build-system.md`

## Notas Técnicas
- Prefijo configurable: `--tgp-color-primary` via `CSS_FRAMEWORK_PREFIX` env
- No usar `@import` en CSS (usa PostCSS nested + Vite entry points)
- PurgeCSS safelist cubre: dark mode, responsive, states, ARIA, RTL, animations
- Code splitting: CSS separado por entry point
- Hash: `[name]-[hash]` para cache busting
- Style Dictionary v4+ para mejor TypeScript support

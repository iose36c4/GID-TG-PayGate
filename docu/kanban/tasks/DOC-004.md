# [[DOC-004]] ADR-003: Subdominios Dinámicos (public, creadores, crm, admin)

## Descripción
Documentar decisión de usar subdominios separados por contexto.

## Código de Ejemplo
```markdown
# ADR-003: Subdominios Dinámicos por Contexto

## Status
Accepted

## Context
TG-PayGate necesita separar contextos de usuario:
- **Public**: Landing, canales, checkout (usuarios finales)
- **Creadores**: Panel creadores (canales, analytics, retiros)
- **CRM/Staff**: Soporte, facturación, moderación
- **Admin**: Config global, métricas, feature flags

## Decision
Usar **subdominios dinámicos** basados en `APP_DOMAIN`:
- `public.{domain}` → Dominio público
- `creadores.{domain}` → Panel creadores
- `crm.{domain}` → CRM/Staff
- `admin.{domain}` → Admin panel

## Decision
Usar subdominios dinámicos con `RouteServiceProvider` + Middleware `EnsureCorrectSubdomain`.

## Implementation
```php
// RouteServiceProvider
public function boot(): void
{
    $domain = config('app.domain');
    
    Route::middleware('web')
        ->domain("public.{$domain}")
        ->group(base_path('routes/domains/public.php'));
    
    Route::middleware(['web', 'auth', 'role:creador'])
        ->domain("creadores.{$domain}")
        ->group(base_path('routes/domains/creadores.php'));
    
    Route::middleware(['web', 'auth', 'role:staff'])
        ->domain("crm.{$domain}")
        ->group(base_path('routes/domains/crm.php'));
    
    Route::middleware(['web', 'auth', 'role:admin'])
        ->domain("admin.{$domain}")
        ->group(base_path('routes/domains/admin.php'));
}
```

## Consecuencias
### Positivas
- Separación clara de contextos (seguridad, UX, SEO)
- SSL wildcard único para todos
- Cookies aisladas por subdominio (seguridad)
- Routing limpio en RouteServiceProvider
- Middleware `EnsureCorrectSubdomain` valida rol ↔ subdominio

### Negativas
- DNS wildcard requerido
- Certificado SSL wildcard necesario
- Complejidad en testing (subdominios en tests)
- Cookies compartidas requieren `domain=.tudominio.com`

## Alternativas
1. **Path-based**: `/creadores`, `/crm`, `/admin` - Simple pero menos隔离
2. **Dominios separados**: `tgp-creadores.com`, `tgp-crm.com` - Múltiples SSL, SEO separado
3. **Path + Query param**: `/app?context=creador` - Feo, no persiste

## Decisión
**Aceptado**: Subdominios dinámicos con middleware `EnsureCorrectSubdomain`.

## Consecuencias
- DNS wildcard `*.tudominio.com`
- Certificado SSL wildcard obligatorio
- Middleware `EnsureCorrectSubdomain` valida rol ↔ subdominio
- Cookies: `domain=.tudominio.com` para sesión compartida

### Webhook IPN
```
POST /webhooks/mercadopago/{channel_id}
```
**Headers:**
- `x-signature`: HMAC SHA256
- `x-request-id`: ID único request

**Payload:**
```json
{
  "topic": "payment",
  "data": { "id": "1234567890" },
  "type": "payment"
}
```

**Validación HMAC:**
```php
$signature = $request->header('x-signature');
$requestId = $request->header('x-request-id');
$data = $requestId . '|' . $request->getContent();
$expected = hash_hmac('sha256', $data, $clientSecret);
hash_equals($expected, $signature);
```

### Métodos de Pago Argentina
- **Tarjetas**: Crédito/Débito (Visa, Mastercard, Amex, Cabal, Naranja, etc.)
- **Dinero en cuenta**: MercadoPago Wallet
- **Efectivo**: PagoFácil, Rapipago, Provincia NET, Cobro Express
- **Transferencia**: Bancaria (CBU/CVU)
- **Cuotas sin interés**: 3, 6, 9, 12 (promos bancarias)

### Webhook
```
POST /webhooks/stripe
```
**Eventos:**
- `checkout.session.completed`
- `invoice.payment_succeeded`
- `invoice.payment_failed`
- `customer.subscription.deleted`
- `charge.refunded`

**Validación:**
```php
$event = \Stripe\Webhook::constructEvent(
    $payload, $sigHeader, $webhookSecret
);
```

## Webhooks Unificados
### Estructura Común
```php
interface WebhookProcessorInterface {
    public function process(string $gateway, array $payload): void;
    public function verifySignature(array $payload, string $signature): bool;
}
```

### Factory
```php
class PaymentGatewayFactory {
    public static function create(string $gateway, array $config): PaymentGatewayInterface {
        return match($gateway) {
            'mercadopago' => new MercadoPagoGateway($config),
            'stripe' => new StripeGateway($config),
            'paypal' => new PayPalGateway($config),
            default => throw new \InvalidArgumentException("Gateway no soportado"),
        };
    }
}
```

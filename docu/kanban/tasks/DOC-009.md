## Canales de Notificación

### Mail Channel
```php
class MailChannel
{
    public function send($notifiable, Notification $notification)
    {
        $message = $notification->toMail($notifiable);
        
        return $this->mailer->send($message->to($notifiable->email))
            ->subject($message->subject)
            ->markdown($message->markdown, $message->data)
            ->withSwiftMessage(function ($msg) {
                $msg->getHeaders()->addTextHeader('X-Entity-ID', $notification->id);
            });
    }
}
```

### Telegram Channel
```php
class TelegramChannel
{
    public function send($notifiable, Notification $notification)
    {
        $bot = new TelegramBot(config('telegram.bot_token'));
        
        $message = $notification->toTelegram($notifiable);
        
        return $this->bot->sendMessage([
            'chat_id' => $notifiable->telegram_id,
            'text' => $message->text,
            'parse_mode' => 'HTML',
            'reply_markup' => $message->replyMarkup,
        ]);
    }
}
```

### Database Channel (In-App)
```php
class DatabaseChannel
{
    public function send($notifiable, Notification $notification)
    {
        $notifiable->notifications()->create([
            'type' => get_class($notification),
            'data' => $notification->toDatabase($notifiable),
            'read_at' => null,
        ]);
    }
}
```

# [[DOC-010]] Guía: Deployment InfinityFree (subdominios, SSL, cron, queue worker)

## Descripción
Guía completa de despliegue en InfinityFree (hosting compartido FTP) con subdominios, SSL, cron jobs y queue workers.

## Código de Ejemplo
```bash
# deploy.sh - Script de despliegue automatizado
#!/bin/bash
set -e

echo "🚀 Iniciando deploy a InfinityFree..."

# 1. Build local
echo "📦 Building assets..."
npm run build:production

# 2. Optimize Laravel
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan optimize

# 3. Preparar archivos para FTP
echo "📁 Preparando archivos..."
rsync -av --delete --exclude '.git' --exclude 'node_modules' --exclude 'tests' \
  --exclude '.github' --exclude '.env' --exclude '.env.*' \
  --exclude 'storage/logs/*' --exclude 'storage/framework/cache/*' \
  --exclude 'storage/framework/sessions/*' --exclude 'storage/framework/views/*' \
  ./ /tmp/deploy-package/

# 4. Subir via lftp
echo "📤 Subiendo via FTP..."
lftp -c "
set ftp:ssl-allow no
open -u $FTP_USER,$FTP_PASS $FTP_HOST
mirror -R --delete --parallel=5 --exclude-glob .git \
  --exclude-glob node_modules \
  --exclude-glob tests \
  --exclude-glob docu \
  --exclude-glob '*.md' \
  --exclude-glob deploy.sh \
  --exclude-glob '.env*' \
  /tmp/deploy-package/ /htdocs/
"

# 5. Symlinks en servidor (ejecutar en servidor via SSH o panel)
echo "🔗 Creando symlinks..."
cat > /tmp/create-symlinks.sh << 'EOF'
#!/bin/bash
cd /home/user
ln -sfn ../vendor htdocs/vendor
ln -sfn ../storage htdocs/storage
ln -sfn ../vendor htdocs/creadores/vendor
ln -sfn ../storage htdocs/creadores/storage
ln -sfn ../vendor htdocs/crm/vendor
ln -sfn ../storage htdocs/crm/storage
ln -sfn ../vendor htdocs/admin/vendor
ln -sfn ../storage htdocs/admin/storage
EOF
chmod +x /tmp/create-symlinks.sh
```

```php
// app/Console/Kernel.php - Cron jobs para InfinityFree
protected function schedule(Schedule $schedule): void
{
    // Limpieza de expirados (cada hora)
    $schedule->command('subscriptions:expire')->hourly();
    
    // Procesar retiros pendientes (cada 5 min)
    $schedule->command('payouts:process')->everyFiveMinutes();
    
    // Limpiar invitaciones Telegram expiradas (cada 30 min)
    $schedule->command('telegram:invitations:cleanup')->everyThirtyMinutes();
    
    // Generar sitemap diario (03:00)
    $schedule->command('sitemap:generate')->dailyAt('03:00');
    
    // Limpiar invitaciones Telegram expiradas (diario 04:00)
    $schedule->command('telegram:invitations:cleanup')->dailyAt('04:00');
    
    // Limpiar logs antiguos (semanal domingo 03:00)
    $schedule->command('log:prune --days=90')->weeklyOn(0, '03:00');
    
    // Backup BD semanal (domingo 04:00)
    $schedule->command('backup:run --only-db')->weeklyOn(0, '04:00');
    
    // Limpiar invitaciones Telegram expiradas (diario)
    $schedule->command('telegram:invitations:cleanup')->daily();
}
```

## Criterios de Aceptación
- [ ] Script deploy.sh automatizado (build + FTP + symlinks)
- [ ] lftp para upload paralelo y mirror
- [ ] Symlinks: vendor/ y storage/ compartidos entre subdominios
- [ ] Cron jobs: expire subscriptions, process payouts, sitemap, cleanup logs
- [ ] SSL wildcard para subdominios (Let's Encrypt)
- [ ] Subdominios configurados: public, creadores, crm, admin
- [ ] Queue worker: supervisor + php artisan queue:work
- [ ] Health check endpoint para monitoring

## Notas Técnicas
- InfinityFree: solo FTP, sin SSH, sin SSH keys
- lftp para mirror incremental con --parallel
- Symlinks requieren acceso SSH o panel de control (crear manualmente si no hay SSH)
- Cron jobs: usar cron de InfinityFree (limitado) o cron externo (cron-job.org)
- Queue worker: supervisor + php artisan queue:work --sleep=3 --tries=3
- SSL: Let's Encrypt wildcard *.tudominio.com
- Subdominios: public, creadores, crm, admin → carpetas separadas en htdocs/

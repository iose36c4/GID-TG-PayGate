# [[DOC-014]] Guía usuario: Admin (config, staff, métricas, feature flags)

## Descripción
Guía completa para administradores del panel Admin: configuración global, gestión de staff, métricas de negocio, feature flags.

## Código de Ejemplo
```markdown
# Guía Admin - TG-PayGate

## Acceso al Panel Admin
- URL: https://admin.tudominio.com
- Credenciales: email + password + 2FA (obligatorio para admin)
- Roles: admin (acceso total), superadmin (configuración global)

## Dashboard Global
- **KPIs Principales**: MRR, ARR, Churn, CAC, LTV, NPS, Funnel adquisición
- **Estado del Sistema**: Uptime, Queue workers, DB connections, Cache hit rate
- **Alertas**: Tickets críticos, Pagos fallidos, SLA breaches, Certificados SSL
- **Acciones rápidas**: Toggle maintenance, Feature flags, Backup manual

## Configuración Global

### Fees y Límites
- **Fee plataforma %**: Porcentaje que TG-PayGate cobra por transacción (default 5%)
- **Fee mínimo por transacción**: Monto mínimo en ARS/USD
- **Máx canales por creador**: Límite de canales por creador (default 10)
- **Máx suscripciones por usuario**: Límite de suscripciones activas por usuario
- **Monedas habilitadas**: ARS, USD, EUR, BRL, MXN, etc.

### Feature Flags
| Flag | Descripción | Rollout | Target |
|------|-------------|---------|--------|
| `affiliate_program` | Programa referidos | 0% | beta |
| `white_label` | Marca blanca creadores | 0% | alpha |
| `multi_currency` | Multi-moneda | 100% | all |
| `advanced_analytics` | Analytics avanzados | 50% | premium |
| `api_public` | API pública v2 | 0% | beta |

### Maintenance Mode
- **Toggle**: ON/OFF inmediato
- **Mensaje personalizado**: HTML permitido
- **Excepciones**: IPs permitidas, rutas excluidas (/health, /webhooks/*)
- **Mensaje personalizado**: HTML con variables {{eta}}, {{reason}}

### Límites y Cuotas
- **Max canales/creador**: 10 (configurable)
- **Max suscripciones/usuario**: 50
- **Monto mínimo retiro**: $1000 ARS / $10 USD
- **Fee mínimo transacción**: $10 ARS / $1 USD
- **Días trial gratis**: 0-30 días (configurable por creador)

## Gestión Staff

### CRUD Staff
- **Crear**: Nombre, email, password, rol (staff/admin)
- **Roles**: staff (tickets), admin (full), superadmin (config global)
- **Permisos granulares**: Ver tickets, responder, reembolsar, gestionar usuarios, configurar sistema
- **2FA obligatorio**: Para admin, opcional para staff

### Auditoría Acciones
- Log automático: usuario, acción, entidad, valores antes/después, IP, timestamp
- Filtros: usuario, acción, entidad, rango fechas
- Export CSV/Excel
- Retención: 2 años

## Métricas de Negocio

### Dashboard Principal
- **MRR/ARR**: Monthly/Annual Recurring Revenue
- **Churn Rate**: Mensual, por cohorte, por canal
- **CAC/LTV**: Customer Acquisition Cost / Lifetime Value
- **NPS**: Net Promoter Score (encuesta trimestral)
- **Funnel Adquisición**: Visitantes → Registros → Trials → Pagos

### Métricas por Canal
- MRR, ARPU, Churn, LTV por canal
- Top creadores por revenue
- Distribución geográfica
- Métodos de pago preferidos

### Transacciones
- Volumen diario/semanal/mensual
- Tasa éxito/fallo por gateway
- Reembolsos/disputas rate
- Tiempo promedio procesamiento

## Feature Flags

### Gestión
- **Crear**: Key, nombre, descripción, rollout %, grupos objetivo, expiración
- **Rollout**: Porcentaje usuarios, grupos objetivo (beta, premium, staff), condiciones custom
- **Kill Switch**: OFF inmediato global
- **A/B Testing**: Variantes A/B, métricas de éxito, significancia estadística

### Grupos Objetivo
- `all`: Todos los usuarios
- `beta`: Usuarios beta testers
- `premium`: Suscriptores premium
- `staff`: Equipo interno
- `creators`: Creadores verificados
- `by_country`: Por país (AR, MX, CO, etc.)
- `by_plan`: free, basic, pro, enterprise

### Condiciones Avanzadas
- `user.plan == 'premium' && user.country == 'AR'`
- `user.created_at > '2024-01-01' && user.channels_count > 0`
- `channel.category == 'finanzas' && channel.price > 1000`

## Métricas y Reportes

### Reportes Programados
- **Diario**: MRR, Churn, Nuevos usuarios, Pagos fallidos (8:00 AM)
- **Semanal**: Churn cohorted, NPS, Feature adoption (Lunes 8AM)
- **Mensual**: Cohort retention, LTV/CAC, Forecasting (1ro cada mes)
- **Trimestral**: Board deck automático (PDF + Slack)

### Exportación
- CSV/Excel/PDF
- Programación: Diario/Semanal/Mensual
- Destino: Email, Slack, S3, Google Sheets

## Criterios de Aceptación
- [ ] Dashboard con KPIs en tiempo real (MRR, Churn, CAC, LTV, NPS)
- [ ] Configuración global: fees, límites, maintenance mode, feature flags
- [ ] Staff management: CRUD, roles, permisos granulares, auditoría
- [ ] Feature flags: rollout %, kill switch, A/B testing, target groups
- [ ] Métricas: MRR, ARR, Churn, CAC, LTV, NPS, Funnel
- [ ] Feature flags: rollout %, kill switch, A/B testing, target groups
- [ ] Reportes: diario/semanal/mensual/trimestral, export CSV/Excel/PDF
- [ ] Documentación completa en Markdown con capturas

## Notas Técnicas
- Feature flags: Redis para evaluación rápida, cache 1 min
- Rollout: consistent hashing user_id para consistencia
- Kill switch: invalida cache inmediatamente
- Audit log: todos los cambios en feature flags
- Rollback: 1-click rollback a versión anterior

## Convenciones de Commits (Conventional Commits)

```
<type>[optional scope]: <description>

[optional body]

[optional footer(s)]
```

### Types
| Type | Descripción |
|------|-------------|
| `feat` | Nueva funcionalidad |
| `fix` | Corrección de bug |
| `docs` | Cambios en documentación |
| `style` | Formato, punto y coma, espacios (sin lógica) |
| `refactor` | Refactor sin cambio de comportamiento |
| `perf` | Mejora de performance |
| `test` | Tests nuevos o modificados |
| `chore` | Mantenimiento, build, deps, config |
| `revert` | Revert commit anterior |
| `security` | Fix de seguridad |
| `ci` | Cambios en CI/CD |

### Scopes (opcional)
```
feat(auth): add 2FA support
fix(checkout): fix race condition in payment
docs(api): update webhook docs
refactor(billing): simplify invoice generation
perf(db): add composite indexes
test(api): add contract tests for webhooks
chore(deps): update dependencies
ci(pipeline): add mutation testing
security(auth): fix 2FA bypass
```

### Breaking Changes
```
feat(api)!: change response format for /api/v1/channels

BREAKING CHANGE: response format changed from array to object with data/meta
```

### Ejemplos
```
feat(billing): add support for Stripe Connect onboarding
fix(checkout): fix race condition in payment processing
docs(api): update webhook documentation for MercadoPago
refactor(billing): simplify invoice generation logic
perf(db): add composite indexes for subscriptions queries
test(api): add contract tests for MercadoPago webhooks
chore(deps): update dependencies to latest versions
ci(pipeline): add mutation testing with Infection
security(auth): fix 2FA bypass vulnerability
```

## Versionado SemVer

### Reglas
- **MAJOR**: Cambios incompatibles en API pública, breaking changes
- **MINOR**: Nueva funcionalidad retrocompatible
- **PATCH**: Bug fixes retrocompatibles
- **PRE-RELEASE**: `-alpha`, `-beta`, `-rc` para pre-releases

### Ejemplos
```
1.0.0  - Primera versión estable
1.0.1  - Bug fix (patch)
1.1.0  - Nueva feature (minor)
2.0.0  - Breaking change en API (major)
1.1.0-beta.1 - Beta release
1.1.0-rc.1 - Release candidate
```

## Automatización Changelog

```bash
# Generar changelog automático (standard-version)
npx standard-version --release-as minor

# O manual con conventional-changelog
npx conventional-changelog -p angular -i CHANGELOG.md -s -r 0
```

```yaml
# .github/workflows/changelog.yml
name: Generate Changelog

on:
  push:
    branches: [main]
    tags: ['v*']

jobs:
  changelog:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      
      - name: Generate Changelog
        run: |
          npx conventional-changelog -p angular -i CHANGELOG.md -s -r 0
      
      - name: Create Release
        uses: softprops/action-gh-release@v1
        with:
          generate_release_notes: true
```

## Versionado en Package.json / composer.json

```json
{
  "name": "tg-paygate/tgp-framework",
  "version": "1.0.0",
  "description": "TG-PayGate Framework CSS",
  "scripts": {
    "version:patch": "npm version patch -m \"chore(release): %s\"",
    "version:minor": "npm version minor -m \"chore(release): %s\"",
    "version:major": "npm version major -m \"chore(release): %s\""
  }
}
```

## Git Hooks (Husky)

```json
// package.json
{
  "husky": {
    "hooks": {
      "commit-msg": "commitlint -E HUSKY_GIT_PARAMS",
      "pre-commit": "lint-staged",
      "pre-push": "npm run test:ci"
    }
  },
  "lint-staged": {
    "*.{php,js,vue,css,md}": ["prettier --write", "eslint --fix"],
    "*.php": ["phpstan analyse", "phpcs --standard=PSR12"]
  }
}
```

```bash
# .commitlintrc.json
{
  "extends": ["@commitlint/config-conventional"],
  "rules": {
    "type-enum": [2, "always", ["feat", "fix", "docs", "style", "refactor", "perf", "test", "chore", "revert", "security", "ci"]],
    "scope-case": [2, "always", "lower-case"],
    "subject-case": [2, "always", "sentence-case"],
    "subject-empty": [2, "never"],
    "header-max-length": [2, "always", 100]
  }
}
```

## Criterios de Aceptación
- [ ] SemVer estricto: MAJOR.MINOR.PATCH + pre-release tags
- [ ] Conventional Commits obligatorios (commitlint + husky)
- [ ] Changelog automático (standard-version / conventional-changelog)
- [ ] GitHub Releases automáticos con notas generadas
- [ ] Git hooks: husky + commitlint + lint-staged
- [ ] Commitlint config: types, scopes, subject-case, header-max-length
- [ ] Lint-staged: prettier, eslint, phpstan en pre-commit
- [ ] Pre-push: test suite completa
- [ ] GitHub Releases: notas automáticas + assets
- [ ] Versionado en package.json + composer.json sincronizado

## Notas Técnicas
- `standard-version` para versionado automático + changelog
- `conventional-changelog` para generar CHANGELOG.md
- `commitlint` + `husky` para validar commits
- `lint-staged` para lint solo archivos staged
- `pre-push` hook para tests antes de push
- GitHub Releases: `softprops/action-gh-release` con provenance
- Breaking changes: footer `BREAKING CHANGE:` en commit
- Versionado sincronizado: package.json + composer.json

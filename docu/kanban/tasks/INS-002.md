# [[INS-002]] Helper `Installation::isInstalled()` (File + Env + Migrations + DB Connectivity)

## Descripción
Implementar helper `Installation::isInstalled()` que verifica: archivo flag, variables de entorno, migraciones ejecutadas y conectividad BD.

## Código de Ejemplo
```php
// app/Helpers/Installation.php
namespace App\Helpers;

use Illuminate\Support\Facades\File;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Schema;
use Illuminate\Support\Facades\Config;

class Installation
{
    public static function isInstalled(): bool
    {
        // 1. Verificar archivo flag
        if (!file_exists(storage_path('installed'))) {
            return false;
        }

        // 2. Verificar .env tiene APP_KEY y credenciales DB
        $envPath = base_path('.env');
        if (!file_exists($envPath)) {
            return false;
        }

        $env = file_get_contents($envPath);
        $required = [
            'APP_KEY',
            'DB_CONNECTION',
            'DB_HOST',
            'DB_PORT',
            'DB_DATABASE',
            'DB_USERNAME',
            'DB_PASSWORD',
        ];

        foreach ($required as $key) {
            if (!preg_match("/^{$key}=.+/m", $env)) {
                return false;
            }
        }

        // 3. Verificar migraciones ejecutadas
        try {
            if (!Schema::hasTable('migrations')) {
                return false;
            }
            $count = DB::table('migrations')->count();
            if ($count === 0) {
                return false;
            }
        } catch (\Exception $e) {
            return false;
        }

        // 4. Verificar conectividad BD real
        try {
            DB::connection()->getPdo();
        } catch (\Exception $e) {
            return false;
        }

        return true;
    }

    public static function markInstalled(): void
    {
        file_put_contents(storage_path('installed'), '1');
    }

    public static function markUninstalled(): void
    {
        if (file_exists(storage_path('installed'))) {
            unlink(storage_path('installed'));
        }
    }
}
```

## Criterios de Aceptación
- [ ] Verifica archivo `storage/installed` existe
- [ ] Verifica `.env` tiene APP_KEY, DB_CONNECTION, DB_HOST, DB_DATABASE, DB_USERNAME, DB_PASSWORD
- [ ] Verifica tabla `migrations` existe y tiene registros
- [ ] Verifica conectividad real a BD (PDO connection)
- [ ] Retorna `bool` - TRUE solo si TODO pasa
- [ ] Métodos auxiliares: `markInstalled()`, `markUninstalled()`

## Notas Técnicas
- Usar `Storage::disk('local')->exists('installed')` para portabilidad
- Cache opcional: `Cache::remember('installed_check', 3600, fn() => ...)`
- Excepciones capturadas silenciosamente (fail closed)
- Método `markInstalled()` llamado al final del instalador

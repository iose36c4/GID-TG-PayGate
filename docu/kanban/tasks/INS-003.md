# [[INS-003]] Rutas `routes/install.php` (Throttle, CSRF, Sin Auth, Rate Limit)

## Descripción
Crear rutas dedicadas para el instalador aisladas del resto de la aplicación: sin autenticación, con throttle, CSRF y rate limiting.

## Código de Ejemplo
```php
// routes/install.php
<?php

use Illuminate\Support\Facades\Route;

Route::prefix('install')->name('install.')->group(function () {
    // Middleware: sin auth, con throttle, CSRF
    Route::middleware(['web', 'throttle:install'])->group(function () {
        // Paso 1: Requisitos
        Route::get('/', fn() => redirect()->route('install.requirements'))
            ->name('index');
        Route::get('requirements', [InstallController::class, 'requirements'])
            ->name('requirements');

        // Paso 2: Base de Datos
        Route::get('database', [InstallController::class, 'database'])
            ->name('database');
        Route::post('database', [InstallController::class, 'testDatabase'])
            ->name('database.test');
        Route::post('migrate', [InstallController::class, 'migrate'])
            ->name('migrate');

        // Paso 2.5: Pasarelas de Pago (PUB-018)
        Route::get('payment-gateways', [InstallController::class, 'paymentGateways'])
            ->name('payment-gateways');
        Route::post('payment-gateways', [InstallController::class, 'savePaymentGateways'])
            ->name('payment-gateways.save');

        // Paso 2.6: Configuración Fiscal (PUB-019)
        Route::get('fiscal-config', [InstallController::class, 'fiscalConfig'])
            ->name('fiscal-config');
        Route::post('fiscal-config', [InstallController::class, 'saveFiscalConfig'])
            ->name('fiscal-config.save');

        // Paso 3: Migraciones + Seeders
        Route::post('migrate', [InstallController::class, 'runMigrations'])
            ->name('migrate.run');

        // Paso 4: Admin Inicial
        Route::get('admin', [InstallController::class, 'admin'])
            ->name('admin');
        Route::post('admin', [InstallController::class, 'saveAdmin'])
            ->name('admin.store');

        // Paso 5: Finalizar
        Route::post('complete', [InstallController::class, 'complete'])
            ->name('complete');
    });
});

// Rate limiter específico para instalador
// bootstrap/app.php o AppServiceProvider
RateLimiter::for('install', function (Request $request) {
    return Limit::perMinute(10)->by($request->ip());
});
```

```php
// app/Http/Controllers/InstallController.php
namespace App\Http\Controllers;

class InstallController extends Controller
{
    public function requirements()
    {
        $requirements = [
            'PHP >= 8.2' => version_compare(PHP_VERSION, '8.2', '>='),
            'Extensiones: openssl, pdo_mysql, mbstring, curl, gd, zip' => 
                extension_loaded('openssl') && extension_loaded('pdo_mysql') &&
                extension_loaded('mbstring') && extension_loaded('curl') &&
                extension_loaded('gd') && extension_loaded('zip'),
            'Composer' => class_exists('Composer\InstalledVersions'),
            'Escritura .env' => is_writable(base_path('.env')),
            'Escritura storage/' => is_writable(storage_path()),
            'Escritura bootstrap/cache/' => is_writable(base_path('bootstrap/cache')),
        ];

        return view('install.requirements', compact('requirements'));
    }

    public function database()
    {
        return view('install.database');
    }

    public function testDatabase(Request $request)
    {
        $request->validate([
            'db_connection' => 'required|in:mysql,pgsql,sqlite',
            'db_host' => 'required|string',
            'db_port' => 'required|integer|min:1|max:65535',
            'db_database' => 'required|string',
            'db_username' => 'required|string',
            'db_password' => 'nullable|string',
        ]);

        $config = $request->only(['db_connection', 'db_host', 'db_port', 'db_database', 'db_username', 'db_password']);
        
        try {
            $pdo = new \PDO(
                "{$config['db_connection']}:host={$config['db_host']};port={$config['db_port']};dbname={$config['db_database']}",
                $config['db_username'],
                $config['db_password']
            );
            $pdo->setAttribute(\PDO::ATTR_ERRMODE, \PDO::ERRMODE_EXCEPTION);
            
            return response()->json(['success' => true, 'message' => 'Conexión exitosa']);
        } catch (\Exception $e) {
            return response()->json(['success' => false, 'message' => $e->getMessage()], 422);
        }
    }

    public function migrate()
    {
        try {
            Artisan::call('migrate', ['--force' => true]);
            return response()->json(['success' => true, 'message' => 'Migraciones ejecutadas']);
        } catch (\Exception $e) {
            return response()->json(['success' => false, 'message' => $e->getMessage()], 500);
        }
    }

    public function admin()
    {
        return view('install.admin');
    }

    public function saveAdmin(AdminStoreRequest $request)
    {
        $user = User::create([
            'name' => $request->name,
            'email' => $request->email,
            'password' => Hash::make($request->password),
            'role' => 'admin',
            'email_verified_at' => now(),
        ]);

        $user->assignRole('admin');

        return redirect()->route('install.complete');
    }

    public function complete()
    {
        // Ejecutar seeders
        Artisan::call('db:seed', ['--force' => true]);
        
        // Marcar como instalado
        \App\Helpers\Installation::markInstalled();
        
        // Limpiar cache
        Artisan::call('optimize:clear');
        
        return redirect()->route('home')->with('success', '¡Instalación completada!');
    }
}
```

## Criterios de Aceptación
- [ ] Archivo `routes/install.php` creado y cargado en `bootstrap/app.php`
- [ ] Grupo de rutas con prefix `install`, name `install.`
- [ ] Middleware: `web`, `throttle:install` (10 req/min/IP)
- [ ] Sin middleware `auth` en todo el grupo
- [ ] Rate limiter `install`: 10 req/min por IP
- [ ] CSRF habilitado en formularios POST
- [ ] Rutas: requirements, database, test-db, migrate, payment-gateways, fiscal-config, admin, complete
- [ ] Rate limiter `install` configurado en `AppServiceProvider` o `bootstrap/app.php`

## Notas Técnicas
- `RateLimiter::for('install', ...)` en `AppServiceProvider`
- `throttle:install` aplicado al grupo
- CSRF habilitado en todos los POST
- Rutas nombradas: `install.requirements`, `install.database`, `install.database.test`, etc.
- Controlador `InstallController` con métodos para cada paso

```php
// app/Http/Controllers/InstallController.php - Método requirements
public function requirements()
{
    $requirements = [
        'php_version' => [
            'name' => 'PHP >= 8.2',
            'description' => 'Versión actual: ' . PHP_VERSION,
            'status' => version_compare(PHP_VERSION, '8.2', '>='),
        ],
        'openssl' => [
            'name' => 'Extensión OpenSSL',
            'description' => 'Requerida para cifrado y HTTPS',
            'status' => extension_loaded('openssl'),
        ],
        'pdo_mysql' => [
            'name' => 'Extensión PDO MySQL',
            'description' => 'Conexión a base de datos MySQL',
            'status' => extension_loaded('pdo_mysql'),
        ],
        'mbstring' => [
            'name' => 'Extensión mbstring',
            'description' => 'Manejo de cadenas multibyte',
            'status' => extension_loaded('mbstring'),
        ],
        'curl' => [
            'name' => 'Extensión cURL',
            'description' => 'Peticiones HTTP a APIs externas',
            'status' => extension_loaded('curl'),
        ],
        'gd' => [
            'name' => 'Extensión GD',
            'description' => 'Procesamiento de imágenes',
            'status' => extension_loaded('gd'),
        ],
        'zip' => [
            'name' => 'Extensión Zip',
            'description' => 'Compresión/descompresión archivos',
            'status' => extension_loaded('zip'),
        ],
        'file_permissions' => [
            'name' => 'Permisos de escritura',
            'description' => 'storage/, bootstrap/cache/, .env escribibles',
            'status' => is_writable(storage_path()) && 
                       is_writable(base_path('bootstrap/cache')) &&
                       is_writable(base_path('.env')),
        ],
        'functions' => [
            'name' => 'Funciones PHP críticas',
            'description' => 'exec, shell_exec, proc_open, symlink',
            'status' => function_exists('exec') && function_exists('shell_exec') &&
                       function_exists('proc_open') && function_exists('symlink'),
        ],
    ];

    $allPassed = collect($requirements)->every(fn($r) => $r['status']);

    return view('install.requirements', compact('requirements', 'allPassed'));
}
```

## Criterios de Aceptación
- [ ] Verifica PHP >= 8.2 (version_compare)
- [ ] Verifica 6 extensiones: openssl, pdo_mysql, mbstring, curl, gd, zip
- [ ] Verifica permisos escritura: storage/, bootstrap/cache/, .env
- [ ] Verifica funciones: exec, shell_exec, proc_open, symlink
- [ ] UI: lista con iconos ✓/✗, badge OK/FALTA
- [ ] Botón "Continuar" habilitado solo si todo OK
- [ ] Mensajes descriptivos para cada requisito

## Notas Técnicas
- `version_compare(PHP_VERSION, '8.2', '>=')` para PHP
- `extension_loaded()` para cada extensión
- `is_writable()` para directorios y .env
- `function_exists()` para funciones críticas
- Mostrar versión PHP actual detectada
- Botón "Continuar" deshabilitado si faltan requisitos

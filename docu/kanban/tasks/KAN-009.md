# [[KAN-009]] Automation: Git Hooks (Commit Msg → Mover Tarea), GitHub Actions (PR → Review)

## Descripción
Implementar automatización del Kanban via Git Hooks y GitHub Actions: commit messages mueven tarjetas, PRs mueven a Review.

## Código de Ejemplo
```bash
# .git/hooks/commit-msg (client-side, via husky)
#!/bin/sh
# .husky/commit-msg

COMMIT_MSG_FILE=$1
COMMIT_MSG=$(cat $COMMIT_MSG_FILE)

# Extraer task IDs: [[TASK-123]], fixes #123, closes #456
TASK_IDS=$(echo "$COMMIT_MSG" | grep -oE '\[\[([A-Z]+-[0-9]+)\]\]|fixes? #([0-9]+)|closes? #([0-9]+)' | sed -E 's/.*[[#]?([A-Z]+-[0-9]+).*/\1/' | sort -u)

if [ -n "$TASK_IDS" ]; then
    for TASK_ID in $TASK_IDS; do
        # Llamar API Kanban para mover a In Progress
        curl -X POST "https://api.tgpaygate.com/api/kanban/move" \
            -H "Authorization: Bearer $KANBAN_API_TOKEN" \
            -H "Content-Type: application/json" \
            -d "{\"task_id\": \"$TASK_ID\", \"column\": \"in_progress\", \"commit_sha\": \"$(git rev-parse HEAD)\"}" \
            -s > /dev/null
    done
fi
```

```yaml
# .github/workflows/kanban-sync.yml
name: Kanban Sync

on:
  pull_request:
    types: [opened, reopened, synchronize, closed, merged]
  push:
    branches: [main, develop]
    paths:
      - 'docu/kanban/tasks/**/*.md'

jobs:
  kanban-sync:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup PHP
        uses: shivammathur/setup-php@v2
        with:
          php-version: '8.2'
      
      - name: Install dependencies
        run: composer install --no-dev --optimize-autoloader
      
      - name: Sync Kanban from PR
        if: github.event_name == 'pull_request'
        run: php artisan kanban:sync-from-pr ${{ github.event.pull_request.number }}
        
      - name: Sync Kanban from Commit
        if: github.event_name == 'push'
        run: php artisan kanban:sync-from-commits ${{ github.sha }}
      
      - name: Sync Kanban from Docs
        if: github.event_name == 'push' && contains(github.event.commits.*.modified, 'docu/kanban/')
        run: php artisan kanban:sync-from-docs
      
      - name: Comment on PR
        if: github.event_name == 'pull_request' && github.event.action == 'opened'
        run: |
          gh pr comment ${{ github.event.pull_request.number }} \
            --body "🔄 Kanban sincronizado. Tarjetas relacionadas movidas a **In Progress**."
```

```php
// app/Console/Commands/KanbanSyncFromPR.php
class KanbanSyncFromPR extends Command
{
    protected $signature = 'kanban:sync-from-pr {pr_number}';
    
    public function handle(): int
    {
        $pr = $this->argument('pr_number');
        $pr = GitHub::pullRequest($pr);
        
        // Extraer task IDs del título, body, commits
        $taskIds = $this->extractTaskIds($pr->title . ' ' . $pr->body);
        $taskIds = array_merge($taskIds, $this->extractFromCommits($pr->commits));
        
        foreach ($taskIds as $taskId) {
            $task = KanbanTask::where('external_id', $taskId)->first();
            if ($task && $task->column !== 'in_progress') {
                $task->moveTo('in_progress');
                $task->update(['pr_number' => $pr->number, 'moved_at' => now()]);
            }
        }
        
        if ($pr->state === 'closed' && $pr->merged) {
            // Mover a Done
            foreach ($taskIds as $taskId) {
                $task = KanbanTask::where('external_id', $taskId)->first();
                if ($task) $task->moveTo('done');
            }
        }
        
        return 0;
    }
}
```

```php
// app/Console/Commands/KanbanSyncFromDocs.php
class KanbanSyncFromDocs extends Command
{
    protected $signature = 'kanban:sync-from-docs';
    
    public function handle(): int
    {
        $tasks = KanbanTask::all()->keyBy('external_id');
        
        foreach (glob('docu/kanban/tasks/*.md') as $file) {
            $content = file_get_contents($file);
            $frontmatter = $this->parseFrontmatter($content);
            
            if (isset($frontmatter['tags'])) {
                $status = $this->extractStatus($frontmatter['tags']);
                $taskId = $frontmatter['id'] ?? basename($file, '.md');
                
                $task = KanbanTask::updateOrCreate(
                    ['external_id' => $taskId],
                    ['column' => $status, 'updated_at' => now()]
                );
            }
        }
        
        $this->info('Kanban sincronizado desde docs');
        return 0;
    }
}
```

## Criterios de Aceptación
- [ ] Git hook `commit-msg`: extrae `[[TASK-ID]]`, mueve a In Progress via API
- [ ] GitHub Action `kanban-sync.yml`: PR opened → In Progress, Merged → Done
- [ ] GitHub Action `kanban-docs-sync.yml`: Push a `docu/kanban/tasks/*.md` → sync bidireccional
- [ ] Commit msg parsing: `[[TASK-ID]]`, `fixes #123`, `closes #456`
- [ ] GitHub Action: Comenta en PR cuando sincroniza
- [ ] Rate limiting: GitHub API rate limits respetados
- [ ] Idempotencia: mismo commit/PR no mueve dos veces
- [ ] Frontmatter sync bidireccional: Kanban ↔ Docs

## Notas Técnicas
- Husky para git hooks client-side
- GitHub Actions para server-side sync
- API Kanban: `POST /api/kanban/move` {task_id, column, commit_sha}
- Idempotencia: mismo commit/PR no mueve dos veces
- Frontmatter sync bidireccional: Kanban ↔ Docs
- `external_id` en tareas = `TASK-ID` para matching

# [[PUB-005]] Registro Usuario: Email Verification, Password Setup, Profile Completion

## Descripción
Implementar flujo completo de registro de usuario: captura email, verificación email, setup password, completado de perfil (nombre, username, timezone).

## Código de Ejemplo
```php
// app/Domains/Public/Http/Controllers/RegisterController.php
namespace App\Domains\Public\Http\Controllers;

use App\Models\User;
use Illuminate\Support\Facades\Hash;
use Illuminate\Auth\Events\Registered;

class RegisterController extends Controller
{
    public function show()
    {
        return view('domains.public.auth.register');
    }

    public function store(RegisterRequest $request)
    {
        $user = User::create([
            'email' => $request->email,
            'password' => Hash::make($request->password),
            'name' => $request->name,
            'username' => $request->username,
            'timezone' => $request->timezone ?? 'America/Argentina/Buenos_Aires',
            'locale' => 'es',
            'role' => 'user',
            'email_verified_at' => null,
        ]);

        event(new Registered($user));

        return redirect()->route('verification.notice')
            ->with('success', 'Registro exitoso. Revisa tu email para verificar tu cuenta.');
    }
}
```

```php
// app/Domains/Public/Http/Controllers/EmailVerificationController.php
class EmailVerificationController extends Controller
{
    public function notice()
    {
        return view('domains.public.auth.verify-email');
    }

    public function verify(EmailVerificationRequest $request)
    {
        $user = User::findOrFail($request->route('id'));

        if ($user->hasVerifiedEmail()) {
            return redirect()->route('home')->with('info', 'Email ya verificado');
        }

        if ($user->markEmailAsVerified()) {
            event(new \Illuminate\Auth\Events\Verified($user));
        }

        return redirect()->route('client.dashboard')
            ->with('success', 'Email verificado correctamente. ¡Bienvenido!');
    }

    public function resend()
    {
        if (auth()->user()->hasVerifiedEmail()) {
            return back()->with('info', 'Email ya verificado');
        }

        auth()->user()->sendEmailVerificationNotification();

        return back()->with('success', 'Email de verificación reenviado');
    }
}
```

## Criterios de Aceptación
- [ ] Formulario registro: nombre, username, email, password, password_confirmation, timezone
- [ ] Validaciones: email único, username único (alphanum + _), password min 8 chars
- [ ] Usuario creado: role=user, email_verified_at=null, timezone default Argentina
- [ ] Email verificación enviado automáticamente (queue)
- [ ] Pantalla "Verifica tu email" con botón reenviar
- [ ] Link verificación: token firmado, expiración 60 min, ID + hash
- [ ] Verificación exitosa: email_verified_at=now, event Verified, redirect dashboard
- [ ] Reenviar email: botón en pantalla verificación, rate limit 1/min
- [ ] Token expirado/inválido: mensaje error claro, opción reenviar

## Notas Técnicas
- Laravel `MustVerifyEmail` trait en User model
- `Illuminate\Auth\Events\Registered` + `Verified` events
- `SendEmailVerificationNotification` queued job
- Signed URL: `URL::temporarySignedRoute('verification.verify', 60, ['id' => $user->id])`
- Rate limiter en `verification.send` (1 por minuto)
- `email_verified_at` timestamp en BD

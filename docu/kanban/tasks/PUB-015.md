# [[PUB-015]] Pasarela Transferencias Bancarias: CBU/CVU, Verificación Manual/Automática, Comprobantes

## Descripción
Implementar pasarela de transferencias bancarias para Argentina: validación CBU/CVU (22 dígitos, algoritmo módulo 10), alias CBU, verificación manual/automática, carga de comprobantes, conciliación.

// app/Services/BankTransferService.php
namespace App\Services;

use App\Models\{Subscription, BankTransferOrder, ChannelPago};
use App\Services\ArgentineTaxService;

class BankTransferService
{
    public function createTransferOrder(Subscription $subscription): BankTransferOrder
    {
        $channel = $subscription->channel;
        
        return BankTransferOrder::create([
            'subscription_id' => $subscription->id,
            'channel_pago_id' => $subscription->channel_pago_id,
            'amount' => $subscription->price,
            'currency' => $subscription->currency,
            'destination_cbu' => $subscription->channel->bank_cbu_cvu,
            'destination_alias' => $subscription->channel->bank_alias,
            'beneficiary' => $subscription->channel->bank_holder_name,
            'beneficiary_cuit' => $subscription->channel->bank_holder_cuit_cuil,
            'bank_name' => $subscription->channel->bank_name,
            'status' => 'pending',
            'reference' => "PAYOUT-{$subscription->id}-" . now()->format('YmdHis'),
            'expires_at' => now()->addDays(2),
        ]);
    }

    public function verifyCbu(string $cbu): bool
    {
        // Algoritmo Módulo 10 para CBU (22 dígitos)
        if (!preg_match('/^\d{22}$/', $cbu)) return false;
        
        $weights = [7, 1, 3, 9, 7, 1, 3, 9, 7, 1, 3, 9, 7, 1, 3, 9, 7, 1, 3, 9, 7, 1];
        $sum = 0;
        for ($i = 0; $i < 21; $i++) {
            $sum += (int)$cbu[$i] * $weights[$i];
        }
        $checkDigit = (10 - ($sum % 10)) % 10;
        return (int)$cbu[21] === $checkDigit;
    }

    public function verifyCvu(string $cvu): bool
    {
        // CVU: 22 dígitos, validación similar a CBU pero para cuentas virtuales
        if (!preg_match('/^\d{22}$/', $cvu)) return false;
        // Algoritmo similar a CBU
        return $this->verifyCbu($cvu);
    }

    public function validateAlias(string $alias): bool
    {
        // Alias CBU: 6-20 caracteres alfanuméricos, único en sistema financiero
        return preg_match('/^[a-zA-Z0-9]{6,20}$/', $alias);
    }

    public function processManualVerification(BankTransferOrder $order, array $data): void
    {
        $order->update([
            'status' => $data['approved'] ? 'verified' : 'rejected',
            'verified_at' => now(),
            'verified_by' => auth()->id(),
            'verification_notes' => $data['notes'] ?? '',
            'receipt_path' => $data['receipt_path'] ?? null,
        ]);

        if ($data['approved']) {
            $this->completeSubscription($order->subscription);
        }
    }

    public function processAutomaticVerification(BankTransferOrder $order): void
    {
        // Integración futura con APIs bancarias (Banco Central, Red Link, Banelco)
        // Por ahora: marcado manual por staff
    }

    private function completeSubscription(BankTransferOrder $order): void
    {
        $subscription = $order->subscription;
        $subscription->update([
            'status' => 'active',
            'activated_at' => now(),
            'renews_at' => now()->addMonth(),
        ]);

        // Generar invite link + notificaciones
        app(\App\Services\WebhookProcessor::class)->processApprovedPayment('bank_transfer', [
            'external_reference' => $order->subscription->external_reference,
        ]);
    }
}

// app/Models/BankTransferOrder.php
class BankTransferOrder extends Model
{
    protected $fillable = [
        'subscription_id', 'channel_pago_id', 'amount', 'currency',
        'destination_cbu', 'destination_alias', 'beneficiary', 'beneficiary_cuit',
        'bank_name', 'status', 'reference', 'expires_at',
        'verified_at', 'verified_by', 'verification_notes', 'receipt_path',
    ];

    protected $casts = [
        'amount' => 'decimal:2',
        'expires_at' => 'datetime',
        'verified_at' => 'datetime',
    ];

    public function subscription()
    {
        return $this->belongsTo(Subscription::class);
    }

    public function channel()
    {
        return $this->belongsTo(ChannelPago::class);
    }

    public function verifier()
    {
        return $this->belongsTo(User::class, 'verified_by');
    }
}

// app/Http/Controllers/Checkout/BankTransferController.php
class BankTransferController extends Controller
{
    public function show(Subscription $subscription)
    {
        $order = BankTransferOrder::where('subscription_id', $subscription->id)->latest()->firstOrFail();
        return view('domains.public.checkout.bank-transfer', compact('subscription', 'order'));
    }

    public function uploadReceipt(Subscription $subscription, BankTransferReceiptRequest $request)
    {
        $order = BankTransferOrder::where('subscription_id', $subscription->id)->latest()->firstOrFail();
        
        $path = $request->file('receipt')->store('bank-transfer-receipts', 'public');
        
        $order->update([
            'receipt_path' => $path,
            'transferred_amount' => $request->amount,
            'transferred_at' => $request->transferred_at,
            'user_notes' => $request->notes,
            'status' => 'receipt_uploaded',
        ]);

        // Notificar staff para verificación
        app(\App\Services\TelegramService::class)->notifyStaffNewReceipt($order);

        return redirect()->route('checkout.bank-transfer.show', $subscription)
            ->with('success', 'Comprobante subido. Lo verificaremos en menos de 24hs hábiles.');
    }
}

## Criterios de Aceptación
- [ ] Validación CBU: 22 dígitos, algoritmo Módulo 10 (dígito verificador)
- [ ] Validación CVU: 22 dígitos, algoritmo similar a CBU
- [ ] Alias CBU: 6-20 caracteres alfanuméricos
- [ ] Vista checkout: datos cuenta destino (banco, titular, CUIT, CBU, alias, tipo cuenta)
- [ ] Instrucciones claras: monto exacto, concepto con referencia, subir comprobante 24h
- [ ] Upload comprobante: JPG/PNG/PDF max 5MB, monto, fecha/hora, notas
- [ ] Verificación staff: aprobar/rechazar, notas, activar suscripción + invite link
- [ ] Expiración orden: 48h, luego cancelada automáticamente
- [ ] Notificaciones: email/Telegram usuario y staff
- [ ] Testing: CBU válidos/inválidos, upload archivos, flujo completo

## Notas Técnicas
- CBU: 22 dígitos, dígito verificador Módulo 10 (pesos: 7,1,3,9,7,1,3,9,7,1,3,9,7,1,3,9,7,1,3,9,7,1)
- CVU: 22 dígitos, similar a CBU para cuentas virtuales (MercadoPago, Ualá)
- Alias CBU: 6-20 chars alfanuméricos, único en sistema financiero
- Verificación manual inicial, API bancaria futura (Banco Central, Red Link, Banelco)
- Comprobante: max 5MB, JPG/PNG/PDF, almacenar en storage privado
- Expiración 48h, job diario cancela órdenes expiradas
- Staff: panel CRM con lista pendientes, visor comprobante, botones aprobar/rechazar

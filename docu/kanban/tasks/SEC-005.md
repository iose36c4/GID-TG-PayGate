# [[SEC-005]] Money Value Object (integer cents, nunca float)

## Descripción
Implementar el Value Object `Money` como núcleo del dominio financiero. **Prohibido float**: todo el dinero se representa como entero en la unidad menor (centavos/cents), con moneda asociada y operaciones aritméticas exactas (suma, resta, multiplicación por ratio, comparación, serialización).

## Código de Ejemplo
```php
namespace App\Domains\Financiero\ValueObjects;

final readonly class Money
{
    public function __construct(
        private int $amountInCents,
        private Currency $currency,
    ) {
        if ($amountInCents < 0) {
            throw new InvalidMoneyAmount($amountInCents);
        }
    }

    public static function fromDecimal(float|string $decimal, Currency $currency): self
    {
        if (is_float($decimal) && !is_finite($decimal)) {
            throw new InvalidMoneyAmount($decimal);
        }
        return new self(
            (int) round((float) $decimal * 100, 0, PHP_ROUND_HALF_UP),
            $currency,
        );
    }

    public function add(Money $other): self
    {
        $this->assertSameCurrency($other);
        return new self($this->amountInCents + $other->amountInCents, $this->currency);
    }

    public function subtract(Money $other): self
    {
        $this->assertSameCurrency($other);
        return new self($this->amountInCents - $other->amountInCents, $this->currency);
    }

    public function toDecimal(): string // nunca float
    {
        return bcdiv((string) $this->amountInCents, '100', 2);
    }

    public function amountInCents(): int { return $this->amountInCents; }
    public function currency(): Currency { return $this->currency; }
}
```

## Criterios de Aceptación
- [ ] `Money` inmutable, con `amountInCents: int` y `Currency`
- [ ] Sin floats en cálculos: `bcmath` para cualquier división
- [ ] Lanza excepción si monedas distintas (no mezclar ARS/EUR/USD)
- [ ] `toDecimal()` retorna string (nunca float) para salidas/JSON
- [ ] Serialización en DB como BIGINT cents (columna `*_amount_cents`)
- [ ] Property-based tests con invariantes (ver SEC-046)

## Notas Técnicas
- Dependencia `ext-bcmath` declarada en composer.json (validar en INS-001)
- Regla: **nunca** usar `float` en modelos, controladores o cálculos financieros
- Comparar siempre con `amountInCents` int, nunca con decimales flotantes
- Este VO es bloqueante de todo el resto del dominio financiero

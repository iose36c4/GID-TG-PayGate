# [[SEC-006]] Currency + Multi-moneda (ISO 4217)

## Descripción
Modelar `Currency` como VO (código ISO 4217, decimal places, símbolo, locale de formato) y diseñar el soporte multi-moneda desde el inicio aunque v1.0 opere principalmente en ARS. Incluir tabla `currencies` (seed) y servicio de conversión con tasas y política de redondeo explícita.

## Código de Ejemplo
```php
namespace App\Domains\Financiero\ValueObjects;

final readonly class Currency
{
    public function __construct(
        public string $code,        // 'ARS', 'USD', 'EUR'
        public int $decimalPlaces,  // 2
    ) {
        if (!preg_match('/^[A-Z]{3}$/', $code)) {
            throw new InvalidCurrencyCode($code);
        }
    }

    public function minorUnitMultiplier(): int
    {
        return 10 ** $this->decimalPlaces; // ARS -> 100
    }

    public function roundToMinor(int $value): int
    {
        return (int) round($value / $this->minorUnitMultiplier()) * $this->minorUnitMultiplier();
    }
}

// app/Domains/Financiero/Services/CurrencyConversionService.php
public function convert(Money $amount, Currency $to, float $rate): Money
{
    // rate: USD->ARS = 900.50
    $converted = bcmul((string) $amount->amountInCents(), (string) $rate, 4);
    $rounded = $to->roundToMinor((int) bcround($converted, 0));
    return new Money($rounded, $to);
}
```

## Criterios de Aceptación
- [ ] VO `Currency` con validación ISO 4217
- [ ] Tabla `currencies` + seed (ARS, USD, EUR, BRL, MXN, COP...)
- [ ] Servicio de conversión con `bcmath`, tasa explícita y política de redondeo
- [ ] Decisión documentada: redondeo `ROUND_HALF_UP` y a qué unidad
- [ ] Multi-moneda no rompe comparaciones (comparar solo misma moneda)
- [ ] ADR que fija la estrategia multi-moneda v1.0 (moneda por canal)

## Notas Técnicas
- v1.0: moneda por canal (cada creador elige su moneda); conversión solo donde aplique
- Guardar siempre la moneda original y el monto en `Money` para evitar pérdidas
- No aplicar tasas automáticas sin persistir la tasa usada en el asiento
- Considerar MXN/BRL si se quiere expandir LatAm: ISO listado desde el inicio

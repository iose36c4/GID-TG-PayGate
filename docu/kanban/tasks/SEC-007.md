# [[SEC-007]] Entidades del Dominio Financiero

## Descripción
Modelar las entidades del dominio financiero como **agregados con identidad propia** (no modelos Laravel genéricos): `Invoice`, `Payment`, `Balance`, `Withdrawal`, `Refund`, `Settlement`, `Commission`, `Fee` y `Transfer`. Cada entidad vive en `app/Domains/Financiero/Entities`, es inmutable en su núcleo y solo se modifica a través de sus métodos de dominio.

## Código de Ejemplo
```php
// app/Domains/Financiero/Entities/Invoice.php (esqueleto)
namespace App\Domains\Financiero\Entities;

use App\Domains\Financiero\ValueObjects\Money;

final class Invoice
{
    public function __construct(
        public readonly string $id,
        public readonly string $creatorId,
        public readonly string $customerId,
        public readonly Money $amount,
        private InvoiceState $state = InvoiceState::Created,
    ) {}

    public function markPaid(Payment $payment): void
    {
        if (!$this->state->canTransitionTo(InvoiceState::Paid)) {
            throw new InvalidStateTransition($this->state, InvoiceState::Paid);
        }
        $this->state = InvoiceState::Paid;
        $this->paidPaymentId = $payment->id;
    }

    public function state(): InvoiceState { return $this->state; }
}
```

## Criterios de Aceptación
- [ ] Entidades creadas: Invoice, Payment, Balance, Withdrawal, Refund, Settlement, Commission, Fee, Transfer
- [ ] Todas usan `Money` para importes (nunca float)
- [ ] Identidades propias (ULID/UUID), no autoincrementales
- [ ] Métodos de dominio con validación de transición de estado
- [ ] Mapa de agregados y sus relaciones documentado (Mermaid en docu)
- [ ] No hay lógica financiera en Controladores ni modelos Eloquent de acceso directo

## Notas Técnicas
- Eloquent solo persiste; la lógica de negocio vive en Entidades + Services de dominio
- `Fee`/`Commission` se calculan con `Money::fromDecimal` y ratios exactos (bcmath)
- Separar `Settlement` (cierre con pasarela) de `Withdrawal` (salida a creador)
- Relaciones: Payment → 1 Invoice → N LedgerEntries

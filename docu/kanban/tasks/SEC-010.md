# [[SEC-010]] Invariantes de Balance + Auditoría de Consistencia

## Descripción
Definir y verificar las **invariantes del ledger** en cada operación y de forma periódica: todo `entry_group` cuadra, no hay saldos negativos en cuentas de responsabilidad, cada payment tiene asientos consistentes, y las agregaciones coinciden con fuentes externas. Implementar `LedgerAuditService` (job programado de auditoría + verificación bajo demanda).

## Código de Ejemplo
```php
// app/Domains/Financiero/Services/LedgerAuditService.php
final class LedgerAuditService
{
    public function auditGroup(string $entryGroup): void
    {
        $rows = LedgerEntry::where('entry_group', $entryGroup)->get();
        $sum = $rows->reduce(fn (int $s, $r) => $s + ($r->debit ? $r->amount_cents : -$r->amount_cents), 0);
        if ($sum !== 0) {
            throw new LedgerOutOfBalance($entryGroup, $sum);
        }
    }

    public function auditPayableNonNegative(string $currency): void
    {
        $negative = DB::table('ledger_entries as le')
            ->selectRaw('le.account_id, SUM(CASE WHEN le.debit THEN le.amount_cents ELSE -le.amount_cents END) AS net')
            ->groupBy('le.account_id')
            ->having('net', '<', 0)
            ->get();
        if ($negative->isNotEmpty()) {
            throw new NegativeBalance($negative);
        }
    }
}
```

## Criterios de Aceptación
- [ ] Invariantes documentadas (cuadre, no-negatividad, unicidad por entry_group, trazabilidad)
- [ ] `LedgerAuditService` con auditoría por grupo y por cuenta
- [ ] Job programado (diario) que audita muestras y alerta si falla
- [ ] Comando `php artisan ledger:audit --date=YYYY-MM-DD --full`
- [ ] Checks en CI: auditoría de fixture sobre entorno de tests
- [ ] Cualquier violación genera alerta crítica (ver SEC-038) y bloquea retiros

## Notas Técnicas
- La no-negatividad aplica a cuentas de pasivo (payable_creator); cuentas de activo pueden requerir otras reglas
- Documentar invariantes en el Risk Register como controles de mitigación (RSK-001)
- Es la base de la tarea de reconciliación (SEC-019)

# [[SEC-015]] Disputas/Chargeback + Congelamiento de Fondos

## Descripción
Flujo de **disputas y chargebacks** de pasarela: al recibir notificación de disputa, el payment pasa a `Disputed`, los fondos pendientes al creador se **congelan** (`Frozen`), se crea la disputa con evidencias y plazos, y se resuelve a favor (reembolso) o en contra (devuelve a `Paid`). Bloquea retiros mientras existan disputas activas.

## Código de Ejemplo
```php
final class DisputeService
{
    public function open(Dispute $dispute, Payment $payment): void
    {
        $payment->transitionTo(PaymentState::Disputed);
        // Congelar saldo del creador asociado a este pago
        $this->freeze->amountRelatedTo($payment); // asiento 'frozen_funds'
        $this->audit->record('dispute_opened', $dispute);
    }

    public function resolve(Dispute $dispute, bool $win): void
    {
        if ($win) {
            $dispute->payment->transitionTo(PaymentState::Paid);   // re-libera fondos
            $this->freeze->releaseFor($dispute->payment);
        } else {
            $dispute->payment->transitionTo(PaymentState::Chargeback); // se deduce
            $this->freeze->chargebackFor($dispute->payment);
        }
        $dispute->transitionTo(DisputeState::Resolved);
    }
}
```

## Criterios de Aceptación
- [ ] Entidad `Dispute` con estados (open, under_review, resolved_win, resolved_loss, expired)
- [ ] `Disputed`/`Chargeback`/`Frozen` integrados en máquinas de Payment/Refund/Withdrawal
- [ ] Fondos relacionados congelados con asiento `frozen_funds` (reversible)
- [ ] Regla: no se permite retirar mientras hay disputa activa en el balance del creador
- [ ] Timeline de disputa con plazos (respuesta pasarela, evidencias) y alertas
- [ ] Notificación al creador y staff al abrirse/resolverse

## Notas Técnicas
- La congelación debe ser reversible y postearse en el ledger (no mutar balances)
- Timeout de disputa sin respuesta → resolución automática según política del proveedor
- Registrar chargeback como costo del negocio en cuenta `chargeback_expense`
- Vincular con ADM-006 (transacciones/disputas)

# [[SEC-041]] Sesiones: Fixation, Rotation, Refresh Tokens, Revocación

## Descripción
Endurecer la **gestión de sesiones y tokens de autenticación**: prevenir session fixation (regenerar id en login), rotación de sesión, refresh tokens rotativos, gestión de dispositivos (ver/revocar sesiones activas), y revocación global ante compromiso. Importa para staff/admin/creador (sesiones con dinero).

## Código de Ejemplo
```php
// Regenerar sesión en login/role-change (anti-fixation)
$request->session()->regenerate();
$request->session()->invalidate();

// Recordar sesión activa por dispositivo (tabla user_sessions)
public function login(Request $request): Response
{
    $user = $this->authenticate($request);
    $request->session()->regenerate();

    UserSession::record($user, [
        'ip' => $request->ip(),
        'user_agent' => $request->userAgent(),
        'device_fingerprint' => $fingerprint,
    ]);

    return redirect()->intended();
}

// Revocación de una sesión (UI: "Cerrar esta sesión")
SessionDriver::revoke($user->id, $sessionToken);

// Rotación de refresh tokens (OAuth/sanctum custom)
if (!$old->isFresh()) $this->revokeAndIssueNew($user);
```

## Criterios de Aceptación
- [ ] Regeneración de sesión en login, cambio de rol, elevación de permisos y 2FA
- [ ] Tabla `user_sessions` con IP, user-agent, último acceso y estado
- [ ] UI de gestión de dispositivos (ver todas, revocar individual/global) en perfil
- [ ] Refresh tokens rotativos con revocación en uso detectado
- [ ] Revocación global de sesiones de un usuario por compromiso (kill switch)
- [ ] Sesiones expiradas por inactividad configurable (TST-S-006)
- [ ] Tests de fixation/rotation/revocation

## Notas Técnicas
- Regenerar la sesión en cada elevación de privilegios (2FA, cambio de rol)
- Notificar al usuario cuando se inicia sesión desde dispositivo nuevo
- `session` en `config/session.php`: `secure`, `http_only`, `same_site=lax`, `expire_on_close` opcional
- Complementar con 2FA (CLI-003) y auditoría de logins (SEC-036)

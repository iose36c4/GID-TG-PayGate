# [[SEC-046]] Property-Based Testing del Dominio Financiero

## Descripción
Verificar **invariantes del dominio financiero** con property-based testing (generación aleatoria de casos): propiedades de `Money` (conmutatividad, no-negatividad, suma preserva moneda), invariantes del ledger (cuadre, inmutabilidad, reconstrucción == registro), y máquinas de estado (toda secuencia válida de transiciones mantiene invariantes).

## Código de Ejemplo
```php
// tests/Unit/Financiero/MoneyPropertyTest.php
use Pest\Pest\Property;
use Pest\Pest\Generator;

it('suma de Money es conmutativa', function (int $a, int $b, string $currency) {
    $a = new Money(abs($a), new Currency($currency));
    $b = new Money(abs($b), new Currency($currency));

    expect($a->add($b))->toEqual($b->add($a));
})->with(Property::ints()->map(fn ($v) => abs($v))->combine(Property::currencyCode()));

it('ledger reconstruido == suma de asientos (invariante global)', function (array $entries) {
    $ledger = Ledger::reconstruct($entries);   // función pura
    $manual = array_reduce($entries, fn ($s, $e) => $s + ($e['debit'] ? $e['amount'] : -$e['amount']), 0);

    expect($ledger->balance())->toBe($manual);
    expect($ledger->isBalanced())->toBeTrue();
})->with(Property::ledgerGroups());

it('toda transición válida preserva el estado en el dominio', ...);
```

## Criterios de Aceptación
- [ ] Props de Money: conmutativa, asociativa, no-negativa, preserva moneda, round-trip decimal↔cents
- [ ] Props del ledger: balance() == suma, cuadre por entry_group, inmutabilidad (reject write)
- [ ] Props de máquinas de estado: secuencias aleatorias válidas sin estados ilegales
- [ ] Seed fijo + configuración para reproducir fallos
- [ ] Reporte de contraejemplos encontrados (mejora continua)
- [ ] Corrida en CI (rápida) + nightly (grande)

## Notas Técnicas
- Herramientas: Pest Plugins (Pest\Pest) o `gigablah/php-faker` / custom generators
- Los contraejemplos de Money casi siempre descubren redondeos flotantes → confirma bcmath (SEC-005)
- Property tests complementan (no reemplazan) los unit tests explícitos
- Definir invariantes desde SEC-008/010 y verificar que se cumplen siempre

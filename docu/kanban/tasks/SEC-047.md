# [[SEC-047]] Pentest Ofensivo I: SSRF, XXE, IDOR, Mass Assignment, Host Header

## Descripción
Suite de **pruebas ofensivas** (tests automatizados + checklist manual) sobre las categorías más peligrosas para un gateway: **SSRF** (webhooks salientes, fetch de URLs de creadores), **XXE** (XML de proveedores), **IDOR** (acceso a recursos ajenos), **Mass Assignment** (campos inyectados) y **Host Header Injection** (links generados con host malicioso).

## Código de Ejemplo
```php
// tests/Feature/Security/OffensiveTest.php
test('SSRF: fetch de URL del creador no alcanza red interna', function () {
    Http::preventStrayRequests();
    $blocked = ['http://169.254.169.254/', 'http://10.0.0.1/', 'http://localhost/'];

    foreach ($blocked as $url) {
        $this->assertThrows(
            fn () => $webhookFetcher->fetch($url),
            SsrfBlocked::class,
        );
    }
});

test('IDOR: creador no accede a payments de otro', function () {
    $other = Payment::factory()->for(Channel::factory()->for(Creator::factory()))->create();
    $me = User::factory()->creator()->create();

    $this->actingAs($me)->getJson("/api/v1/payments/{$other->id}")
        ->assertForbidden();
});

test('Mass Assignment: role inyectado en registro no aplica', function () {
    $this->postJson('/register', [...valid, 'role' => 'admin', 'permissions' => ['*']]);
    expect(User::latest()->first()->role)->toBe('user');
});

test('Host Header: links generados usan host allowlist, no el header', function () {
    $this->withHeaders(['Host' => 'evil.com'])->postJson('/checkout', $data);
    // Los correos/enlaces generados usan config('app.url'), no el Host
});
```

## Criterios de Aceptación
- [ ] SSRF: cliente HTTP saliente bloquea loopback/red privada/metadata; allowlist por protocolo/dominio
- [ ] XXE: deshabilitado (Laravel `simplexml` con `LIBXML_NONET`, o sin parseo de XML externo)
- [ ] IDOR: matriz completa cubierta por tests (SEC-027/025) — cero accesos cruzados
- [ ] Mass Assignment: `$fillable`/`forceFill` auditados, campos de rol/estado no inyectables
- [ ] Host Header: generación de URLs SIEMPRE desde config/app, nunca del request
- [ ] Checklist manual documentada + resultado en Risk Register (SEC-003)

## Notas Técnicas
- El cliente HTTP de Laravel con `Http::preventStrayRequests()` en tests bloquea llamadas no falsedas
- SSRF: DNS rebinding mitigation (resolver y verificar, o usar allowlist estricto)
- Cada categoría con test automático; el pentest manual lo coordina SEC-048/049
- Verificar no solo la respuesta HTTP sino los efectos de escritura (ledger, DB)

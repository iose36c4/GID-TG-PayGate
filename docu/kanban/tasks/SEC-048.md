# [[SEC-048]] Pentest Ofensivo II: Smuggling, Cache Poisoning, Zip Bomb, Timing

## Descripción
Pruebas ofensivas avanzadas de **transporte y parsing**: HTTP Request Smuggling (CL.TE/TE.CL contra proxy/InfinityFree), Cache Poisoning (headers de caché en páginas autenticadas), Zip Bomb / Billion Laughs (subidas y XML), Path Traversal (uploads, descargas) y **Timing Attacks** (comparaciones y búsquedas que filtran información).

## Código de Ejemplo
```php
// tests/Feature/Security/TransportTest.php
test('request smuggling: doble Content-Length rechazado', function () {
    $this->withHeaders(['Content-Length' => '10', 'Transfer-Encoding' => 'chunked'])
        ->postJson('/webhooks/stripe', []);
    // -> 400 o rechazado por el servidor (verificado en staging con proxy real)
});

test('cache poisoning: respuesta autenticada no cacheable', function () {
    $r = $this->actingAs(staff())->getJson('/admin/transacciones');
    expect($r->headers->get('Cache-Control'))->toContain('private, no-store');
    expect($r->headers->has('ETag'))->toBeFalse();
});

test('zip bomb en subida rechazada (ratio/tamaño)', function () {
    UploadedFile::fake()->create('bomb.zip', 4096) // ratio 1000:1
    $response = $this->actingAs(staff())->post('/admin/import', ['file' => $file]);
    $response->assertStatus(422);
});

test('timing: login no revela existencia de email', function () {
    // comparar duración email-existente vs no-existente (con hashing forzado)
    $a = timeit(fn () => $this->post('/login', ['email' => 'no@existe.com', 'password' => 'x']));
    $b = timeit(fn () => $this->post('/login', ['email' => User::factory()->create()->email, 'password' => 'x']));
    expect(abs($a - $b))->toBeLessThan(50);
});
```

## Criterios de Aceptación
- [ ] Smuggling: headers dobles rechazados; verificado en staging con el proxy real
- [ ] Cache poisoning: páginas autenticadas con `Cache-Control: private, no-store`; headers de caché auditados
- [ ] Zip Bomb: límite de tamaño y ratio de compresión en uploads; no expandir sin límite
- [ ] Billion Laughs: XML con entidades externas deshabilitado (refuerza XXE de SEC-047)
- [ ] Path Traversal: filenames sanitizados (`basename`, Storage con aislamiento)
- [ ] Timing: comparaciones constant-time (`hash_equals`), login sin oracle de email
- [ ] Resultados registrados en Risk Register

## Notas Técnicas
- Smuggling se prueba con el stack real del deploy (InfinityFree proxy) en staging
- Path traversal aplica a descarga de facturas PDF y uploads de comprobantes (PUB-015)
- Timing: usar `hash_equals` y hashing simulado del password inexistente
- Reforzar con TST-S-008 (file upload) y TST-S-010 (headers)

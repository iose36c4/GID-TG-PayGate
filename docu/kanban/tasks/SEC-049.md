# [[SEC-049]] Pentest Ofensivo III: JWT/OAuth, CSRF/CSP Bypass, Unicode, Prototype Pollution, Dependency Confusion

## Descripción
Pruebas ofensivas de **identidad, frontend y dependencias**: JWT/OAuth attacks (algoritmo, expiración, replay de refresh), CSRF bypass y **CSP bypass**, Clickjacking, Unicode normalization (homógrafos en emails/slugs), Prototype Pollution (JS/Alpine) y **Dependency Confusion** (paquetes privados vs públicos). Cierre del ciclo ofensivo.

## Código de Ejemplo
```php
// tests/Feature/Security/IdentityTest.php
test('JWT: algoritmo no confiable rechazado', function () {
    $token = (new Builder)->header('alg', 'none')
        ->claims(['sub' => 1, 'role' => 'admin'])->getToken();
    $this->getJson('/api/v1/me', ['Authorization' => "Bearer $token"])->assertUnauthorized();
});

test('CSRF bypass: petición cross-origin con cookie bloqueada', function () {
    $this->withoutMiddleware(VerifyCsrfToken::class) // solo para probar que SAME_ORIGIN/Origin check está
        ->postJson('/checkout', $data, ['Origin' => 'https://evil.example'])
        ->assertStatus(403);
});

test('unicode: emails/slugs normalizados a NFC para evitar homógrafos', function () {
    $this->postJson('/register', ['email' => 'usuario@gmaí­l.com']); // homoglifo i/y
    // Normalización + allowlist de caracteres
});
```

## Criterios de Aceptación
- [ ] JWT: alg none/HS256-forzado rechazados; expiración y audiencia validadas
- [ ] Refresh tokens: reuso detectado → revocación total (SEC-041)
- [ ] CSRF: tokens por sesión + verificación de origen; test cross-origin
- [ ] CSP: sin bypass conocido; `script-src` sin `unsafe-inline` salvo justificación revisada
- [ ] Clickjacking: `X-Frame-Options: DENY` + CSP `frame-ancestors 'none'`
- [ ] Unicode: normalización NFC y validación de emails/slugs (homógrafos)
- [ ] Prototype Pollution: revisión de dependencias JS + guards en manejo de JSON
- [ ] Dependency Confusion: packages privados con `repositories` explícitos; test de CI
- [ ] Todo registrado en Risk Register (SEC-003)

## Notas Técnicas
- Como no hay backend OAuth propio (login propio + sesiones), el foco JWT está en tokens de API y proveedores
- Prototype pollution aplica al frontend Alpine.js/JS: fijar Object.prototype y sanitizar JSON.parse
- Dependency confusion: nombres de paquetes privados no deben existir en Packagist; verificar `composer audit` (TST-S-002)
- Coordinar el checklist manual con el pentest externo (si aplica) pre-GA
